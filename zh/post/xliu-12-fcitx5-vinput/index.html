在 Fedora 上为 Fcitx5 配置语音输入

刘训臣

八月 3, 2026

Linux 桌面一直缺一个好用的系统级语音输入方案。最近发现了 fcitx5-vinput——一款 Fcitx5 的原生语音输入插件，支持本地模型和云端 ASR，延迟低，集成度高。

安装

Fedora 用户通过 COPR 安装：

sudo dnf copr enable xifan/fcitx5-vinput-bin
sudo dnf install fcitx5-vinput

装完后启动后台服务：

systemctl --user enable --now vinput-daemon.service

打开 Fcitx5 配置工具（fcitx5-configtool），在插件列表中启用 Vinput。然后启动图形界面 vinput-gui。

配置 ASR 引擎

Vinput 支持本地离线模型和云端服务两种语音识别方案。

本地模型

如果比较注意隐私，可以用本地模型。在 Resources → Models 中下载 sherpa-onnx 模型。这里我下载了一个比较小的模型测试。

云端方案：阿里云百炼

本地模型测试下来效果一般，转向云端方案。注册阿里云百炼，创建 API Key。

在 Vinput GUI 中，Resources → ASR Providers → Install，选择 Aliyun Bailian（bailian-streaming）。

也可以直接编辑配置文件 ~/.config/vinput/config.json，在阿里云模型下面添加：

{
    "id": "provider.bailian.batch",
    "type": "command",
    "command": "python3",
    "args": [
        "/home/xliu/.local/share/vinput/providers/bailian/batch"
    ],
    "env": {
        "VINPUT_ASR_API_KEY": "sk-ws-xxxx",
        "VINPUT_ASR_LANGUAGE": "",
        "VINPUT_ASR_MODEL": ""
    },
    "timeout_ms": 60000
}

其中 language 和 model 都空着不填就可以，只需要填上 API Key。

配置完成后回到输入法，按右 Alt 键即可触发语音输入。

排错记录

过程中踩了几个坑：

“voice input daemon is not responding” — 后台服务没启动，systemctl --user start vinput-daemon.service 解决。

ASR Providers 列表为空 — 配置文件 ~/.config/vinput/config.json 中 registry 字段缺失，补全即可；或者检查网络是否能访问 GitHub。

“missing vinput asr api key” — 忘记在 Control 页面设 API Key。

“provider closed stdin” — Provider 进程崩溃，检查 API Key 正确性和网络，用 journalctl --user -u vinput-daemon.service -f 查看详细日志。

使用

默认右 Alt 触发，支持点按切换和按住说话两种模式。按 F8 可在本地模型和云端引擎间切换。

LLM 集成

Vinput 还支持接入大语言模型，可以在语音识别后对文本进行润色或翻译。在设置中选择 LLM Type 为 DeepSeek，填入 API Key 即可调用。

小结

语音输入能大大提高效率。fcitx5-vinput 填补了 Linux 桌面语音输入多年的空白，安装配置虽有几处小坑，但搞定后体验流畅。值得一提的是该项目 GitHub 仓库非常活跃，遇到问题可以直接提 Issue。
