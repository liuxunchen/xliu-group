激光燃烧诊断的下一步：从「能测」到「测得可信、测得有用」

刘训臣

十一月 14, 2026

今年课题组的两条线越走越清楚。

一条是高频多场同步：20 kHz 的单相机双色甲醛 PLIF 测温、高重频的 PLIF/PIV 同步、40 kHz 的 TDLAS/PLIF/PIV 三诊断同步测量剪切层动力学。另一条是TDLAS 的机器学习反演：用 U-Net 从更少的扫描数据里重建层流扩散火焰的二维温度与 CO₂ 浓度场。

这两条线合起来，回答的是「能不能测、测得快不快、能不能同时测」。但越往下做，越觉得真正的问题在往后移——测得快、测得全，不等于测得可信；实验室里「精心对准」出来的漂亮场图，搬到真实燃烧室边上，未必还站得住。

我们把这件事归结成一条主线：从「在理想实验室环境中获取高精度数据」，走向「在真实、极端、动态的工业环境中，提供可靠、多维、可解释的定量信息」。这条主线下面，有五个技术方向值得加强，外加一块常被低估的试验场——而它们恰好都落在我们已经打出的牌上。

一、极端条件：从实验室火源到 3500 K、300 bar 的燃烧室

真实的燃烧系统——航空发动机加力与主燃、火箭发动机、重型燃气轮机——环境极为苛刻：温度可以超过 3500 K，压力从真空一直跨到 300 bar 以上，同时伴随强烈振动，光学访问常常只剩几个小窗口。

现有的自发拉曼散射、PLIF 在这样的条件下会同时遇到三件事：信噪比恶化（高压下碰撞淬灭、谱线展宽与重叠）、穿透深度不足（高密度、强背景辐射）、时间分辨率受限（信号弱就得拉长曝光或累加）。

所以需要重点加强的是适用于极端环境的诊断原理与系统，而不是把实验室系统原样放大。两个具体方向：

  • 飞秒激光超短脉冲成像。飞秒脉冲的峰值功率高、脉宽远短于淬灭与解离的时间尺度，可以在 kHz 速率下对 H、O、N 等关键活性原子与分子做无干扰成像。这是「高温高压下还能拿到自由基场」的一条现实路径。
  • 激光吸收光谱层析成像（LAST）的工程化。把 TDLAS 的分子特异性与断层重建结合起来，从有限条视线积分反演燃烧室内部的温度、组分与压力二维/三维场。它天生适合「只有几个窗口」的发动机环境，但代价是反演问题病态。

我们在这条线上其实已经有了一块扎实的地基：多路 TDLAS 层析系统——32 路平行光路加旋转扫描、面向发动机喷管温度/浓度场成像；配 串脉冲（burst）激光与 MHz 级 TDLAS 提供高重频光源；再加上反射式 TDLAS 解决受限光路下的访问。三样拼起来，正是「极端条件 + 有限光学窗口」需要的组合。缺的不是原理，是把它们做成在振动、高温、长时运行下仍然靠得住的系统。

二、多参数同步：从「同时看」到「知道有多准」

燃烧是流动、传热与化学反应的强耦合过程。单点、单参数的测量已经不够用，这一点国际上早就形成共识：

  • CARS 与 NO-MTV 结合，在脉冲高焓流场里做 100 kHz 量级的温度、速度同步测量；
  • 扫频串脉冲滤波瑞利散射（FRS）做到 20 kHz 串脉冲、1 ms 时均，等价 1 kHz 同时测温度、压力与径向速度（Braun 等，2025）；
  • NASA 的官方综述干脆把「瞬时多参数（含压力）测量」判定为唯一尚未解决的空白。
  • 频率扫描 PLIF（FS-PLIF）则试图从单次激发中同时提取温度、压力与速度，绕开多参数之间的耦合——思路很对，真正的难点同样落在标定与不确定度上。

我们自己的积累也在这条线上：高重频的 PLIF/PIV 同步（声激励下抬升旋流火焰）、20 kHz 单相机双色甲醛 PLIF 测温、40 kHz 的 TDLAS/PLIF/PIV 三诊断同步，以及反射式 TDLAS 与自发光高速摄影的同步测量。这些工作解决的是「同时看」。

但下一步的核心矛盾不是帧率，而是这把「同时」到底有多准。高频同步测量产生的是海量数据，而多系统之间的时空配准误差、各技术自身的系统偏差、以及有限投影角度下层析重建的病态性，会共同构成一个很少被系统量化的不确定度包络。当测量对象从稳定的旋流火焰走向强瞬态、强振荡工况时，这个包络可能直接决定结论可靠不可靠——我们看到的「精细场图」，也许只是把误差画得更漂亮了。

所以我们认为要加强的是：面向多参数同步数据集的联合不确定度传播框架。让每一次高频同步测量都附带可验证的置信区间，而不是只呈现一张看起来精细的场图。

这条线我们已经在动手：正在推进的面上项目里有一个子课题做石英片合束的多模态融合测量——把红外 TDLAS 与 355 nm/532 nm 片光同轴耦合到同一探测面，要求亚毫米级的空间对准与亚微秒级的时序同步，再用路径积分结果与全场结果互相标定。它表面上是个光路工程问题，实质上是把「配准误差」从隐含假设变成可测量量的一次实验。

三、工业在线：从实验装置到机匣上的模块

实验室里的精密系统往往体积庞大、对环境要求苛刻；而工业应用——发动机健康监测、燃烧优化、排放控制——需要的是紧凑、鲁棒、抗干扰、可原位的测量方案。真实发动机的诊断环境是：有限光学窗口、强振动、背景辐射干扰、长时在线运行。

这要求诊断技术在设计层面就做出改变，而不是把实验室系统「搬过去」：

  • 固定结构的 TDLAS 传感器：通过创新的光学架构摆脱对机械扫描部件的依赖，在振动环境下保持光路稳定；
  • 有限投影 LAST 的稳健反演：投影角度少、噪声大，重建的伪影与敏感性必须靠算法解决，而不是靠增加光路；
  • 激光超声等在线监测手段：把诊断从「燃烧场测量」延伸到高温部件（如发动机叶片）的疲劳损伤监测，进入运维环节。

我们已经有的那块拼图是反射式 TDLAS 与 PIV/PLIF 同步拍摄的专利思路（CN121252888B）：反射式光路把「发射—接收」压到同一侧，天然适配单侧光学访问。沿着这个思路再往前一步，就是从「需要精密对准的实验装置」变成「可以拧在机匣上的测量模块」。

这既是工程问题，也会反过来驱动测量原理：当视线数被限制到个位数、投影角度只有几十度时，如何在反演层面保证鲁棒性？这个问题的答案，可能比多买几台激光器更有价值。

四、AI：从「加速器」到「物理可信的推理引擎」

2022 年我们用 U-Net 做了层流扩散火焰的二维温度与 CO₂ 浓度场反演（Fuel 324: 124447），核心贡献是用更少的扫描测量数据、更高效地重建二维场，解决传统多视线扫描「系统复杂、效率不佳」的问题。这是一个正确的起点。

但如果停留在这个层面，机器学习就只是一个加速器。真正需要加强的是物理一致性与泛化能力：

  • 对象偏移：轴对称层流扩散火焰是一个相对受控的对象。模型学到的映射，在工况偏移时是否仍然成立？从层流走向湍流、从常压走向高压、从甲烷走向掺氢/掺氨——这些是还没有回答的问题。
  • 物理约束：纯数据驱动的反演可能给出精度尚可、却违反守恒定律的场。需要把守恒方程、辐射传输先验嵌进网络结构或损失函数，发展 物理信息神经网络（PINNs）与物理感知的重建方法。
  • 不确定度：用 贝叶斯不确定性量化（UQ）让模型不只输出场，还输出可信度分布。这是从「看起来准」到「知道哪里不准」的关键一步。
  • 在线自适应：从「离线训练—固定部署」走向「在线自适应标定与迁移」，让反演在工况、燃料、光学窗口变化时具备自我修正能力。

我们其实已经把 AI 放进了测量链的多个环节：PIV 的光流法与 AI 流场计算、DMD/SPOD 模态分解、基于火焰图像的贫燃熄火预测。下一步是把它们统一到一个框架里——输出不仅快、而且物理上可信、不确定度可量化。终点是自主传感系统：根据现场的信噪比、谱线重叠与窗口污染程度，自己决定扫描策略、激光功率与积分时间。

五、零碳燃料：抢先建立特征组分的诊断选择性

能源转型正在把燃烧系统推向氨、氢等零碳/低碳燃料，以及旋流、贫预混、MILD 等新燃烧模式。这些变化从根本上改变了流场动力学、温度分布与化学反应路径，对诊断技术提出了全新的选择性要求。

氨燃烧诊断的核心难点不在「能不能用激光测」，而在于在强烈的 CO₂/H₂O 背景干扰下，实现对 NH、NH₂、HNO 等关键含氮中间体的选择性探测；氢燃烧则对 OH/NO 的定量、以及高温下谱线展宽与偏移的精确建模提出更高要求。

我们在中红外 TDLAS 与分子光谱学上的积累是切入这个方向的天然优势——醚类燃料低温氧化过氧化物、运输替代燃料的中红外吸收光谱，这些工作练的就是「在复杂背景下挑出特征谱线」的本事。具体该做的不是泛泛地「做氨氢」，而是聚焦氨/氢火焰中现有诊断手段信噪比不足或选择性不够的特征组分：

  • 发展针对性的吸收/荧光谱线策略（波段选择、调制方式、背景扣除）；
  • 用飞秒 PLIF 对氨/氢混合火焰中的 NH 做高重频成像；
  • 与旋流火焰的高频成像能力结合，回答一个更本质的问题：零碳燃料的火焰结构与热释放耦合关系，是否发生了根本性改变？

诊断技术的发展需要与新型燃烧系统的研发协同演进，而不是等燃烧器定型了再跟进。

六、井下与工业现场：把最苛刻的场景当试金石

课题组还有一块不那么「燃烧」的业务：井下气体检测与工业现场检测。表面上看，这与追求高时空分辨的燃烧诊断是两条路——空间极度受限、环境恶劣、长期稳定性要求极高、常常无人值守。

但如果把它当成「低端应用」，就浪费了它的战略价值。恰恰相反，它是一个约束条件下的技术验证场：在低信噪比、强干扰、无人值守的条件下给出可信读数，会逼着研究者去解决那些在实验室里可以被「精心对准」掩盖的问题——基线漂移、光学污染、温度—应力耦合误差、长期漂移。

我们正在做的深部煤炭原位项目就是这样一个场景：10–25 MPa、高水蒸气/CO₂ 的活性气氛、井下空间与供电都受限，却要求原位、长时的激光诊断。

建议把这一块从「应用出口」提升为「鲁棒性反哺」的支点：把在井下与工业现场锤炼出来的抗干扰算法、自校准策略、失效诊断逻辑，反向注入发动机在线诊断模块的开发，形成「严苛场景验证 → 核心诊断模块加固」的闭环。

七、结语：一个系统工程问题

把上面几条合起来看，激光诊断研究的加强，本质上是一个系统工程问题。它不是在单一技术指标上追求「更高、更快、更强」，而是需要同步推进四个层面：

  • 原理层面：对极端条件的适应性（飞秒、LAST、高重频光源）；
  • 系统层面：多参数集成与工程鲁棒性（单侧访问、无扫描、抗振动）；
  • 数据层面：物理可信的 AI 与可量化的不确定度；
  • 应用层面：与新型燃料、工业场景的深度咬合。

这几个层面相互依存，任何一个环节的短板都会制约整体诊断能力的提升。

对我们课题组而言，真正要补的是三个关键环节：给同步测量赋予可量化的不确定度、让机器学习反演获得物理可信性与泛化能力、把诊断系统从「实验装置」锻造成「在线工具」。在此基础上，以氨/氢特征组分诊断为零碳时代的切入点，以井下与工业现场为鲁棒性的试金石。

这不是另起炉灶。高频多场同步与 TDLAS 机器学习反演这两张牌已经打出去了，下一步是在它们的延长线上，把「先进」做成「不可替代」。
