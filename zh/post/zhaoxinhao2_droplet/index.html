OpenPIV颗粒与液滴辨别

OpenPIV：

在流体力学实验中，气液两相流、液液两相流的流场分析常面临一个核心难题——颗粒（多为示踪粒子）与液滴难以精准区分，而这直接影响流场参数计算的准确性。这时，OpenPIV就成了区分的好帮手。 OpenPIV是一款开源的粒子图像测速（PIV）软件，基于Python开发，凭借强大的图像预处理、相位分离及粒子识别功能，能够高效处理粒子图像，提取运动参数。它无需复杂的付费授权，且支持自定义参数、脚本化自动化处理，适配从宏观到微尺度的各类两相流场景，尤其适合需要精准区分不同粒子（颗粒与液滴）的实验需求，是科研、实验中不可或缺的实用工具。 在气泡雾化的研究中我们想依托OpenPIV的核心功能，建立高效、准确的颗粒与液滴辨别流程，实现两类目标的精准分割、特征提取及运动参数区分，解决气液两相流中颗粒（示踪粒子）与液滴（分散相/连续相液滴）易混淆的问题，为后续流场分析提供可靠的目标分类基础。核心是通过参数优化和算法筛选，使辨别准确率达到90%以上，满足PIV测量中两相流场的分离分析需求。

下面列举了一些判断的依据：

  1. 颗粒与液滴的图像特征差异（粒径大小、灰度强度、边缘清晰度、运动特性）；
  2. OpenPIV软件内置相位分离、动态掩膜、粒子滤波等核心功能（如phase_separation模块、preprocess模块）；
  3. 相关文献及OpenPIV官方教程中相位分离方法（如Khalitov & Longmire方法、中值滤波法）；
  4. 实验场景的实际需求（如颗粒为示踪粒子、液滴为研究对象，或反之）。

辨别颗粒与液滴需要的一些设备：

  1. 成像设备：高速相机（分辨率≥1024×768，帧率≥100fps），配备显微镜头（微尺度场景）或普通镜头（宏观场景），确保清晰捕捉颗粒与液滴的轮廓及细节；
  2. 光源系统：激光光源（波长532nm优先，适配荧光示踪粒子）或LED面光源，避免反光干扰，保证颗粒与液滴的灰度对比度；

编程软件算法准备：

1.核心软件：OpenPIV（Python版本）； 2. 依赖库：NumPy、SciPy（图像滤波、数组运算）、Matplotlib（图像显示与可视化）、OpenCV（辅助图像预处理）； 3. 辅助工具：Jupyter Notebook（代码调试、分步执行）、图像查看器（如IrfanView，预处理检查）。

拍照需要采集的东西：

  1. 采集包含颗粒与液滴的两相流图像样本，涵盖不同实验工况（不同流速、浓度），保证样本代表性；
  2. 样本要求：图像清晰，无明显噪声、模糊或反光；颗粒与液滴的尺寸、灰度有可区分差异（如颗粒粒径小、灰度均匀，液滴粒径大、边缘有反光）；
  3. 样本数量：静态图像≥50张，动态序列图像≥10组（每组≥50帧），用于算法调试、参数优化及准确率验证。

此外我们还要进行采集样本的预处理：

  1. 格式统一：转换为OpenPIV支持的格式（.png、.tif），确保图像尺寸一致；
  2. 噪声去除：通过OpenPIV内置滤波（high_pass、median_filter）或OpenCV高斯滤波，避免噪声误判为微小颗粒/液滴；
  3. 灰度调整：利用OpenPIV的intensity_clip功能，增强颗粒、液滴与背景的对比度，便于后续特征提取；
  4. 图像标注：手动标注≥20张样本，明确颗粒与液滴的位置、轮廓，用于后续准确率验证。

预处理完成之后 导入预处理后的样本图像

利用OpenPIV的tools模块及Matplotlib，查看灰度直方图、颗粒/液滴尺寸分布；然后提取4大核心特征，精准区分两类目标： （1）尺寸特征：通过OpenPIV粒子检测功能，统计粒径范围（像素单位），通常颗粒10-50μm，液滴50-200μm，明确尺寸差异； （2）灰度特征：分析灰度均值、方差，颗粒灰度均匀、方差小，液滴因反光导致方差大； （3）边缘特征：利用OpenPIV的dynamic_masking功能（edges方法）提取边缘，颗粒边缘清晰规则，液滴边缘易因反光模糊或出现亮环；（4）运动特征（动态样本）：通过OpenPIV计算粒子位移，颗粒跟随流体运动，速度与流体一致，液滴速度可能偏离。最后算平均速度

选择合适的算法

基于特征分析结果，优先测试以下2种核心算法，对比辨别效果，搭配辅助算法提升准确率：

  1. 中值滤波法（median_filter_method）：利用侵蚀-膨胀滤波（开运算）去除微小颗粒，保留较大液滴，再通过掩码提取微小颗粒，适合尺寸差异明显的场景；核心参数：kernel_size（必须为奇数）、thresh_factor（掩码阈值）；
  2. Khalitov & Longmire方法：通过设定尺寸、亮度阈值，结合开运算去除微小区域，实现两相分离，适合尺寸、灰度均有差异的场景；核心参数：big_particles_criteria（液滴筛选）、small_particles_criteria（颗粒筛选）、opening_ksize（开运算核尺寸）；
  3. 辅助算法：动态掩膜（dynamic_masking），通过边缘或灰度阈值掩膜目标区域，辅助区分边缘模糊的液滴与清晰的颗粒，核心参数：filter_size、threshold。以手动标注样本为参考，逐步优化核心参数，确保准确率达到90%以上：1. 中值滤波法优化：（1）kernel_size：从3、5、7、9等奇数逐步调整，避免过度滤波导致液滴轮廓失真；（2）thresh_factor：在1.0-1.2之间调整，确保掩码准确区分液滴与颗粒；2. Khalitov & Longmire方法优化：（1）尺寸阈值：设定颗粒max_size和液滴min_size，明确尺寸边界；（2）亮度阈值：设定min_brightness、max_brightness，排除背景干扰；（3）opening_ksize：设为3或5，去除微小噪声，避免误判；3. 优化验证：每调整一组参数，对比辨别结果与手动标注结果，计算准确率，记录最优参数组合。

基于最优参数，通过Python代码搭建完整流程，实现批量自动化处理，步骤如下：

  1. 导入模块：from openpiv import tools, phase_separation, preprocess
  2. 图像导入：读取预处理后的静态/动态样本；
  3. 预处理：调用preprocess.high_pass或preprocess.median_filter去除噪声，调用preprocess.intensity_clip调整灰度；
  4. 相位分离（核心）：调用选定算法（如phase_separation.median_filter_method），输入最优参数，得到颗粒图像和液滴图像；
  5. 特征验证：提取分离后两类目标的尺寸、灰度特征，验证与前期分析一致；
  6. 结果保存：保存分离后的图像及辨别结果（坐标、尺寸），用于后续分析。

最后我们要对结果进行误差分析与修正：

  1. 误差类型分析： （1）尺寸重叠误差：小液滴与大颗粒尺寸重叠，结合灰度、边缘特征补充筛选； （2）噪声干扰误差：噪声未完全去除，优化滤波参数，增加high_pass滤波步骤； （3）反光干扰误差：液滴反光导致边缘模糊，调整光源角度或优化动态掩膜参数；
  2. 误差修正：调整流程参数，重新验证，直至误差率低于10%。

####实操注意事项 1.样本质量是辨别准确率的关键，需确保图像无明显噪声、反光，颗粒与液滴特征差异显著； 2.参数调整需循序渐进，每次仅调整一个参数，对比验证结果，避免无法定位最优参数； 3.动态序列图像处理时，需保证帧间图像一致性（光源、相机位置不变），避免外界干扰； 4.若颗粒与液滴尺寸、灰度差异小，可结合荧光示踪技术，通过滤镜分离荧光信号，提升准确率；

下面为实际操作和代码测试

首先通过连续照片判断出图片中的背景 二值化处理（设定阈值），并利用时间序列数据通过傅里叶变换去除背景（低频信号保留高频颗粒信号）

找出背景后就要分辨液滴与颗粒，并标出不同的颜色来加以区分 同时大小也不同，液滴的尺寸要大一些，速度慢一些相反 颗粒尺寸就小一点速度快一点代码如下：

# -*- coding: utf-8 -*-
"""
OpenPIV 颗粒与液滴辨别 - 时间+空间双重滤波 + ROI筛选
解决：虚假颗粒（边缘噪点）问题，只保留图像中部区域的真实目标
"""

import os
import cv2
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
from scipy.fft import fft, ifft, fftfreq
from skimage.measure import label, regionprops
from glob import glob
from tqdm import tqdm

# ==================== 用户设置 ====================
INPUT_DIR = r"C:\Users\AMD00\project\350-spray\3_open_piv\xliu_openpiv_test\2024.6.10\20240610-171003"
OUTPUT_DIR = r"C:\Users\AMD00\project\350-spray\3_open_piv\xliu_openpiv_test\result_improved"

# ----- 时间维傅里叶高通滤波参数 -----
CUTOFF_FREQ = 0.05       # 归一化频率，保留高于此频率的成分（变化快的颗粒）

# ----- 空间高通滤波参数（去除大面积背景渐变）-----
USE_SPATIAL_HIGHPASS = True
GAUSSIAN_SIGMA = 15      # 高斯模糊核大小（sigma），越大保留的背景尺度越大

# ----- 二值化参数 -----
BINARY_METHOD = 'otsu'   # 'otsu' 或 'fixed'
FIXED_THRESH = 30

# ----- 颗粒/液滴分离参数（形态学开运算）-----
KERNEL_SIZE = 5          # 开运算核大小（奇数），控制液滴最小尺寸
THRESH_FACTOR = 1.1

# ----- 剔除虚假目标（位置/面积筛选）-----
ROI_ROW_RATIO = (0.4, 0.6)   # 只保留图像高度方向 40%~60% 区域内的目标（根据您的情况，中间一行）
MIN_AREA = 3                 # 最小面积（像素），小于此值认为是噪声
MAX_AREA = 500               # 最大面积（像素），大于此值可能为伪影

# ==================== 1. 加载图像序列 ====================
def load_image_sequence(input_dir):
    img_paths = sorted(glob(os.path.join(input_dir, "*.tif")) + 
                       glob(os.path.join(input_dir, "*.tiff")))
    if not img_paths:
        raise FileNotFoundError(f"未在 {input_dir} 中找到 .tif 文件")
    images = []
    for p in img_paths:
        img = cv2.imread(p, cv2.IMREAD_GRAYSCALE)
        if img is None:
            print(f"警告：无法读取 {p}，跳过")
            continue
        images.append(img)
    if not images:
        raise ValueError("没有有效图像")
    return images, img_paths

# ==================== 2. 时间维 FFT 高通滤波 ====================
def temporal_fft_highpass(images, cutoff_freq):
    """
    images: list of 2D arrays (T, H, W)
    返回：去背景后的图像序列 (T, H, W) uint8
    """
    seq = np.array(images, dtype=np.float32)
    T, H, W = seq.shape
    filtered = np.zeros_like(seq)
    for h in tqdm(range(H), desc="时间FFT去背景"):
        for w in range(W):
            signal = seq[:, h, w]
            fft_vals = fft(signal)
            freqs = fftfreq(T)
            fft_vals[np.abs(freqs) < cutoff_freq] = 0
            new_signal = np.real(ifft(fft_vals))
            filtered[:, h, w] = new_signal
    # 归一化到 0-255
    filtered = filtered - filtered.min()
    if filtered.max() > 0:
        filtered = filtered / filtered.max() * 255
    return filtered.astype(np.uint8)

# ==================== 3. 空间高通滤波（图像减去高斯模糊）====================
def spatial_highpass(image, sigma=15):
    """输入单帧灰度图，输出高频增强图（抑制大面积渐变背景）"""
    blur = cv2.GaussianBlur(image, (0, 0), sigma)
    high = cv2.subtract(image, blur)
    # 将负值置0，并重新拉伸到0-255
    high = high - high.min()
    if high.max() > 0:
        high = high / high.max() * 255
    return high.astype(np.uint8)

# ==================== 4. 二值化 ====================
def binarize(image, method='otsu', fixed_thresh=30):
    if method == 'otsu':
        _, bin_img = cv2.threshold(image, 0, 255, cv2.THRESH_BINARY + cv2.THRESH_OTSU)
    else:
        _, bin_img = cv2.threshold(image, fixed_thresh, 255, cv2.THRESH_BINARY)
    return bin_img

# ==================== 5. 基于形态学分离颗粒/液滴（在二值图上）====================
def separate_by_morphology(binary_img, kernel_size=5, thresh_factor=1.1):
    kernel = cv2.getStructuringElement(cv2.MORPH_ELLIPSE, (kernel_size, kernel_size))
    opened = cv2.morphologyEx(binary_img, cv2.MORPH_OPEN, kernel)   # 保留大区域（液滴）
    droplets = opened
    diff = cv2.absdiff(binary_img, opened)
    _, particles = cv2.threshold(diff, int(diff.mean() * thresh_factor), 255, cv2.THRESH_BINARY)
    particles = cv2.morphologyEx(particles, cv2.MORPH_OPEN, np.ones((3,3), np.uint8))
    return particles, droplets

# ==================== 6. 提取特征 + ROI + 面积筛选 ====================
def extract_features_filtered(binary_mask, original_gray, label_name, 
                               roi_row_range, min_area, max_area):
    if binary_mask.max() == 255:
        binary_mask = binary_mask // 255
    label_img = label(binary_mask, connectivity=2)
    regions = regionprops(label_img, intensity_image=original_gray)
    features = []
    H = original_gray.shape[0]
    row_min, row_max = int(H*roi_row_range[0]), int(H*roi_row_range[1])
    for reg in regions:
        cy = reg.centroid[0]   # 行坐标
        # 位置筛选：只保留中间行区域
        if not (row_min <= cy <= row_max):
            continue
        # 面积筛选
        if not (min_area <= reg.area <= max_area):
            continue
        # 边缘清晰度（可选）
        minr, minc, maxr, maxc = reg.bbox
        crop = original_gray[minr:maxr, minc:maxc]
        edges = cv2.Canny(crop, 50, 150)
        mask_crop = (label_img[minr:maxr, minc:maxc] == reg.label)
        edge_density = np.sum(edges[mask_crop] > 0) / max(reg.area, 1)
        features.append({
            'label': label_name,
            'area': reg.area,
            'eq_diameter': reg.equivalent_diameter,
            'intensity_mean': reg.mean_intensity,
            'intensity_std': reg.intensity_std,
            'edge_density': edge_density,
            'centroid_row': cy,
            'centroid_col': reg.centroid[1],
        })
    return features

# ==================== 主程序 ====================
def main():
    os.makedirs(OUTPUT_DIR, exist_ok=True)
    
    print("1. 加载图像序列...")
    images, img_paths = load_image_sequence(INPUT_DIR)
    print(f"   共 {len(images)} 帧，尺寸 {images[0].shape}")
    
    print("2. 时间维 FFT 高通滤波（去除缓慢变化的背景）...")
    bg_removed = temporal_fft_highpass(images, CUTOFF_FREQ)
    
    if USE_SPATIAL_HIGHPASS:
        print("3. 空间高通滤波（去除大面积连续背景）...")
        bg_removed_spatial = []
        for i in range(len(bg_removed)):
            bg_removed_spatial.append(spatial_highpass(bg_removed[i], GAUSSIAN_SIGMA))
        bg_removed = np.array(bg_removed_spatial)
    else:
        bg_removed = np.array(bg_removed)
    
    print("4. 二值化、分离颗粒/液滴、特征提取（含ROI和面积筛选）...")
    all_particles_feats = []
    all_droplets_feats = []
    
    for idx in tqdm(range(len(bg_removed)), desc="逐帧处理"):
        frame = bg_removed[idx]
        # 二值化
        binary = binarize(frame, method=BINARY_METHOD, fixed_thresh=FIXED_THRESH)
        # 分离颗粒与液滴
        particles, droplets = separate_by_morphology(binary, KERNEL_SIZE, THRESH_FACTOR)
        # 提取特征并筛选（只保留中间行、合适面积）
        p_feats = extract_features_filtered(particles, frame, 'particle',
                                            ROI_ROW_RATIO, MIN_AREA, MAX_AREA)
        d_feats = extract_features_filtered(droplets, frame, 'droplet',
                                            ROI_ROW_RATIO, MIN_AREA, MAX_AREA)
        all_particles_feats.extend(p_feats)
        all_droplets_feats.extend(d_feats)
        
        # 保存结果图
        base = os.path.splitext(os.path.basename(img_paths[idx]))[0]
        cv2.imwrite(os.path.join(OUTPUT_DIR, f"{base}_bg_removed.png"), frame)
        cv2.imwrite(os.path.join(OUTPUT_DIR, f"{base}_binary.png"), binary)
        # 叠加图：颗粒红色，液滴蓝色（只显示筛选后的目标）
        overlay = cv2.cvtColor(frame, cv2.COLOR_GRAY2BGR)
        # 注意：particles/droplets 是经过形态学分离但未做ROI筛选的，我们只画通过筛选的目标
        # 为了方便，重新生成筛选后的二值图
        filtered_particles = np.zeros_like(particles)
        filtered_droplets = np.zeros_like(droplets)
        for f in p_feats:
            # 通过质心坐标重建简单标记（不够精确，仅用于可视化）
            # 更准确的方法是保存二值图，此处简化为在叠加图上画圆点
            cv2.circle(overlay, (int(f['centroid_col']), int(f['centroid_row'])), 3, (0,0,255), -1)
        for f in d_feats:
            cv2.circle(overlay, (int(f['centroid_col']), int(f['centroid_row'])), 5, (255,0,0), -1)
        cv2.imwrite(os.path.join(OUTPUT_DIR, f"{base}_sep.png"), overlay)
    
    # 保存特征表格
    if all_particles_feats:
        pd.DataFrame(all_particles_feats).to_csv(os.path.join(OUTPUT_DIR, "particles_features.csv"), index=False)
    if all_droplets_feats:
        pd.DataFrame(all_droplets_feats).to_csv(os.path.join(OUTPUT_DIR, "droplets_features.csv"), index=False)
    
    # 绘制粒径分布（只包含筛选后的目标）
    plt.figure(figsize=(8,5))
    if all_particles_feats:
        p_diam = [f['eq_diameter'] for f in all_particles_feats]
        plt.hist(p_diam, bins=30, alpha=0.7, label='Particles')
    if all_droplets_feats:
        d_diam = [f['eq_diameter'] for f in all_droplets_feats]
        plt.hist(d_diam, bins=30, alpha=0.7, label='Droplets')
    plt.xlabel('Equivalent Diameter (pixel)')
    plt.ylabel('Count')
    plt.legend()
    plt.title('Size Distribution (ROI filtered)')
    plt.savefig(os.path.join(OUTPUT_DIR, "size_distribution.png"), dpi=150)
    plt.show()
    
    # 统计
    print("\n========== 最终统计（仅中间行区域） ==========")
    print(f"颗粒数量: {len(all_particles_feats)}")
    print(f"液滴数量: {len(all_droplets_feats)}")
    if all_particles_feats:
        p_diam = np.array([f['eq_diameter'] for f in all_particles_feats])
        print(f"颗粒等效直径: 均值={np.mean(p_diam):.2f} px, 标准差={np.std(p_diam):.2f} px")
    if all_droplets_feats:
        d_diam = np.array([f['eq_diameter'] for f in all_droplets_feats])
        print(f"液滴等效直径: 均值={np.mean(d_diam):.2f} px, 标准差={np.std(d_diam):.2f} px")
    print(f"\n结果保存在: {OUTPUT_DIR}")
    
    # 显示第一帧对比
    plt.figure(figsize=(15,5))
    plt.subplot(131); plt.imshow(images[0], cmap='gray'); plt.title('Original')
