用 OpenFOAM 把 HP/SP 算一遍：从 0D 反应器到喷管 CFD

刘训臣

十月 3, 2026

本文承接上一篇《从氢氧焰到液氢液氧火箭喷管：HP/SP 到底在算什么》。 那里我们用 JANAF 表手算 + Cantera 交叉验证，得到燃烧室 T_c = 3729.8 K、 喉道 116.87 bar / 3398 K、出口（A_e/A_t = 10）2.48 bar / 1729 K / 3792 m/s。

这篇换一条路：同一套工况，用 OpenFOAM 从头算一遍。 目的不是"再算一次"，而是回答一个问题：工程 CFD 工具和教学手算，能不能对上？

一、两条腿：0D 与喷管

HP 和 SP 是两种题型：

题型给定量解出在 OpenFOAM 里对应什么
HP焓 H、压力 p温度 T + 平衡组成0D 定压绝热反应器（chemFoam）
SP熵 s、一串压力 p沿等熵线的 T + 组成喷管 CFD（rhoCentralFoam）

工况与上一篇完全一致：液氢/液氧，O/F = 6.0（质量比），即每 mol O₂ 配 2.6456 mol H₂； p_c = 206.843 bar；推进剂 298.15 K 进入，元素标准态 H = 0。

喷管型面（本文用的几何）由特征线法（method of characteristics, MOC）设计得到—— 这是超声速扩张段的标准设计方法：从喉道声速线出发沿特征线推进，让膨胀波在中心线上汇聚， 从而在给定面积比下得到尽量均匀的出口流场；喉道半高与面积比 $A_e/A_t = 10$ 都取设计值。 （详见 §3.1。）

二、HP：燃烧室（定 H 定 P）

chemFoam 是 OpenFOAM 的 0D 反应器：一个网格、没有流动，只解刚性化学 ODE + 能量方程。 能量方程是 h[0] = h0 + integratedHeat，绝热时 integratedHeat = 0，焓严格守恒—— 这正是 HP 的定义。

2.1 做法：直接给平衡态，而不是"点火"

我们按论文口径建算例：T = 298.15 K、p = 206.843 bar、H₂/O₂ 化学计量比。 结果温度纹丝不动——用 Cantera 的定压反应器独立验证，10 秒内温度一点没变。

这是正常的，不是算例错了。 原因在于口径：

热力学只考虑平衡态，不考虑反应过程。 HP 要的是"给定焓和压力，最终平衡在哪"， 而这个终态只取决于 (H, p, 元素组成)，与走什么路径、中间经历什么无关。

所以 0D 反应器从 298 K 的未燃混合物出发"等它自己烧起来"，问的其实是动力学问题 （而 H₂/O₂ 在室温下本就是亚稳的，真实燃烧室靠点火器）。要算平衡态，就直接给一个平衡态意义上的初态。

具体做法：取已经部分反应、但总焓仍为 0 的状态，组成按元素守恒写 O₂ : (1−x)、H₂ : (2.6456−2x)、H₂O : 2x，解

$$\sum_i X_i\, h_i(T) = 0$$

得到 x = 0.30 时 T₀ = 1611.66 K（X(O₂)=0.2092、X(H₂)=0.6114、X(H₂O)=0.1793）。 由于终态与路径无关，这个初态与"从 298 K 点火后烧到平衡"完全等价—— 相当于"燃烧室里已经烧掉了 30 % 的推进剂"。

那 +1.57 K 是哪来的？ 把积分容差从 relTol 1e-3 收到 1e-6 重跑， 结果仍是 3731.4 K，一模一样。所以这 1.57 K 不是积分误差，而是热物性数据本身的细微差别 （例如 GRI 3.0 的 OH 生成焓与 Cantera 用的值差约 360 J/mol）。relTol 1e-3 已经足够。

三、SP：喷管（rhoCentralFoam）

rhoCentralFoam 是密度基、显式、专门做超声速/激波的求解器（Kurganov 通量）。 壁面用 slip（无粘），对应上一篇"绝热、无摩擦、等熵"的假设。

3.1 喷管型面从哪来：特征线法

喷管的扩张段型面不是随便画一条曲线，而是用**特征线法（MOC）**设计出来的：

  • 喉道附近是跨声速区，二维效应明显，需要先用级数解（如 Hall 的跨声速解）修出声速线；
  • 从声速线出发，把轴向马赫数分布沿特征线（左右两族马赫线，$\mathrm{d}y/\mathrm{d}x=\tan(\theta\mp\alpha)$）推进， 让每一道膨胀波在中心线上恰好反射相消，从而获得无激波、出口流场尽量均匀的型面；
  • 面积比 $A_e/A_t$ 确定后，型面终点与出口马赫数就定了（本文 $A_e/A_t=10 \Rightarrow M_e \approx 3.3$）。

这样设计出来的型面，喉道与出口状态才严格落在同一条等熵线上——这也正是上一篇文章里 “喉道由 $u_t=a_t$ 确定、出口由面积比确定"那套算法的几何基础。

声速点自检：喉道处算出 $u_t = 1584.2$ m/s，而当地声速 $a_t=\sqrt{\gamma R T_t}=1590$ m/s，$u_t/a_t = 0.996$——喉道确实是 $M=1$。

读表要点：

  • 完整喷管比"只算扩张段"明显更准（温度差从 1.8 % 收到 0.45 %、压力从 7.1 % 收到 2.9 %、 速度从 1.1 % 收到 0.23 %）。原因清楚：完整算例里喉道位置是解出来的， 而不是从"假定喉道"等熵反解一个超声速入口状态。
  • 剩下的百分之几来自 140×24 粗网格的数值耗散；做设计用之前应补网格无关性研究。
  • 入口第一格（x≈2 mm）压力偏高约 28 %，是入口边界与内部解的匹配问题（无粘 + 固定入口三量）， 从第二格起即正常（195.34 bar vs 设定 195.17 bar，差 0.09 %）。不影响喉道与出口结论。

四、教学手算 vs 工程 CFD：谁验证谁

量JANAF 手算CanteraOpenFOAM
燃烧室 T_c3756 K3729.8 K3731.4 K
喉道 p_t116.9 bar116.87 bar117.02 bar
喉道 T_t3417 K3398 K3399.4 K
出口 u_e3792 m/s3792 m/s3783.3 m/s

三套完全独立的方法（查表手算 / 平衡求解器 / 动力学 + CFD）落在同一个答案上， 差在 0.05 %~0.5 % 量级。这说明：

  1. 上一篇的教学结论是可靠的——HP/SP 的核心确实是"焓守恒 + 化学平衡 + 等熵"这三条， 与用什么工具无关；
  2. CFD 不是"更高级的手算”——它解的是动力学 + 守恒律，能回答手算回答不了的问题 （比如"从 298 K 会不会自己烧起来"）；同时它也带来自己的误差（数值耗散、网格、边界）；
  3. 反过来，手算适合给 CFD 当"体检表"：算例跑出来先看入口能不能对上边界、出口速度对不对， 对不上就说明设置有问题——“边界对照"是最快的一把尺子。

六、小结

  1. HP：OpenFOAM 的 0D 反应器给出 T_c = 3731.4 K，与 Cantera 全平衡差 0.042 %，组成逐项吻合。 关键不是"怎么点火”，而是认清口径：热力学只问平衡态，就直接给平衡态。
  2. SP：完整喷管 CFD 给出喉道 117.02 bar / 3399.4 K（对手算差 0.12 % / 0.04 %）、 出口 3783.3 m/s（差 −0.23 %）、出口温度 1736.7 K（差 0.45 %）。 喉道处 $u_t/a_t = 0.996$，声速点自检通过。
  3. 喷管型面用特征线法设计——这是把"喉道由 $u_t=a_t$ 定、出口由面积比定"这套一维算法 落成真实几何的桥梁。
  4. 下一步：① 用 MOC 生成正式喷管型面曲线、替换本文的验证几何； ② 网格无关性研究（把剩下那百分之几的耗散误差压下去）； ③ 接入 363 高压燃烧实验平台的设计计算（型面坐标 → 面积比迭代 → $C_F$/$I_{sp}$ 预估，与 CEA 互校）。
