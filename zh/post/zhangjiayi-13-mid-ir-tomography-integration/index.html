简介

中红外（2 μm 波段）层析成像系统把"一条光路的吸收测量"扩展成"多路光场交叉的二维重建"——光、电、机三域的集成质量直接决定能不能测到信号、测得准不准。本文按系统架构 → 光 → 电 → 机 → 集成踩坑五节，记录 215 多路 TDLAS 层析成像装置的光机电集成实践。

分工与状态：①架构、②光（除 QCL/宽谱调谐）、④机 由张家艺主笔；③电 与 ②中激光器调谐部分由赵鑫浩补；⑤踩坑 两人各记各的。素材全部取自 prj_log/215-MHz-TDLAS.md（子课题 C/E/H/L/M/N/O/P/Q/R 与 w43–w44 导师指导 T 号）。

一、系统架构

一条完整链路是：光源 → 光纤分束 → 准直出射 → 穿越被测场 → 收集与聚焦 → 探测器阵列 → 同步采集 → 层析重建。

本项目最终选的是旋转平行光路：固定扇束方案要 ~3217 路才能覆盖同样分辨率，旋转方案只要 32 路——1.6 m 测量区、光路间距 50 mm、重建 32×32 网格；一圈取 100 个角度，采样率 2.0 时重建质量达到"优秀"。这一条既是装置的创新点，也是专利 215-a（旋转筒体层析吸收成像）的核心。

两个设计约束值得单独说：

  • 角度与转速耦合：转速基准 1 rps、可调 0.5–2.0 rps，角度数 = 每圈触发位点数（磁栅尺 100 位点/圈），所以"采多少个投影"是机械与触发共同决定的，不是软件里改个循环数。
  • 光源冗余：两套 1948 nm／1962 nm DFB（单线、先打通链路）＋ 一台 1940–1960 nm 宽谱可调谐激光器（测多线、压力），共用一套 2 μm 光纤放大器（TDFA）——功率放大只买一份，但两套光源的接口与光路必须提前统一。

二、光

  • 分束与传输：1×16 光纤分束器＋光纤准直器阵列。分束后的第一难题不是"有没有光"，而是各路功率是否均衡——熔保/分束比偏差会被后面跨阻增益放大成路间不一致，重建图上就是一条假条纹。因此每路都单独记耦合损耗，链路损耗预算在仿真阶段先做完（N1-1、N1-9），再按预算选型采购。
  • 片光与整形：准直器 → 凹柱面透镜 → 凸柱面镜（两方向：一方向平行、一方向聚焦成片光）→ 穿越测试区 → 锗透镜聚焦 → 探测器（2026-07-30 导师确认）。2 μm 波段不能用普通玻璃，窗口与透镜材料按波段选（锗、ZnSe 类），这也是"窗口/镀膜"要提前和机械加工一起定的原因——先算光学再开孔。
  • 对光次序：先可见光、后红外（N1-12）。可见光能看见光斑、能判断准直与焦点位置；等机械位置都对了再换红外——否则你无法区分"没对准"和"没功率"。
  • 教训两条：光纤器件的规格必须先定再买（二合一光纤首批不合用、重新定制，L2-2）；尾纤是整套系统里最脆的部位（1948 nm 台尾纤断、寄回厂家维修，期间"找信号"整条工作暂停）。

待赵鑫浩补：DFB/宽谱激光器的调谐与线宽实测、驱动参数、QCL 相关选型口径。

三、电

  • 同步时序：磁栅尺读数头输出增量式脉冲，既测转速又给每圈 100 个位点触发；触发信号送采集卡外部触发，保证"投影角度"和"采集时刻"是同一个时钟域。另配 LED 测转速＋圈数作冗余，两路互为校验。
  • 闭环控制的分层：单片机读数 → 算转速 → PID → 直接控变频器（不经过 PC）；上位机（LabVIEW）只做转速显示、目标值下发与数据记录。实时性放在单片机一侧，是因为采集一旦和显示抢同一台机器，触发抖动就会进重建结果。
  • 信号链：探测器 → 跨阻放大（TIA）→ 滤波 → 采集。前端运放选型与带宽按 1–2 MHz 的信号带宽精算，而不是一味追高带宽——带宽富余换来的噪声与自激，代价比收益大。
  • 噪声与干扰：光电流本身小（nA–μA 量级），任何地环路与电磁耦合都会盖住信号。做法是三件：每路独立屏蔽盒（16 路分别屏蔽）、星形单点接地、电缆按长度分档布线避免耦合。采购阶段就把"每路自带屏蔽盒"写进指标（供应商可定制则直接买带屏蔽版本），比事后自己焊盒子省事。
  • 通道分配：采集卡为定制方案（叶老师），需求清单按通道数／采样率／分辨率／量程耦合／触发同步／数据吞吐六项提炼——先把清单写全再谈选型，否则卡在"通道够、触发不够"。

待赵鑫浩补：采集卡实测通道分配与触发接线；工控机与采集软件口径由张家艺补（343 工控机方案与采集卡需求清单同源）。

四、机

  • 旋转主体：多层圆筒 CT 主体图已定稿、下料加工；导师口径「桶不用改，只改桶上单独安装结构」——所有微调件都做成装在主体上的独立小件，不返工主体。圆筒维持铜管水冷，并补两端热防护。
  • 框架：8080 铝型材＋压紧方案，框架结构经加固与尺寸复核后定版；发射/接收窗口开口高度与窗口框架按接口清单三方对接（设计—加工—光学一次对齐，避免"加工完发现窗口挡光"）。
  • 微调机构是创新点：发射端上下微调（螺纹副）、接收端镜子二维微调（弹簧＋螺纹副），结构仿索雷博、带刻度、可读调节量。三条硬要求：① 抵的面不能是圆弧（球抵圆弧不稳），改方接触/点接触；② 可动件要装在人伸手好调的位置——“装上去之后不好动"等于没调；③ 30 多套探测器都要能原位调，调完锁死。
  • 固定与防护：激光器用亚克力板＋盒子固定并规划位置；放大器（EDFA）类器件搬运与安装必须减震（现场测试吃过教训）；机柜内设备固定＋金属盒封装兼顾静电屏蔽与防摔。
  • 一个反直觉的收获：激光器买错规格（60 买成 600）之后不是"凑合用”，而是寄回厂家装好再发回——回来体积更大，倒逼重新设计固定与转接方案，顺带把"买回来不知道怎么装"的问题提前暴露了。规格错了要改结构，不要改测量目标。

五、集成踩坑实录

  1. 打上去总没信号——先怀疑"没对准"是错的，真因常常是探测器没聚焦在焦点（装歪了）。做法：把探测器装正、让它围绕焦点动；位置对了仍没信号，就稍微调、边调边看（高寅斌找信号法）。结论：对光先对焦点，再谈功率与波长（T76、T68）。
  2. 没放激光也有波形——光电板出现 10 MHz／50 MHz 振荡，判为运算放大器自激振荡（短路或 PCB 布局不当）。对策：逐路屏蔽盒＋星形接地，而不是一把抓调增益（O2-3）。
  3. 探测器加电压毫无反应——环境光过强导致饱和。对策：先用黑胶带遮挡测暗电流，确认偏置与电流正常，再逐步引入光信号（APD 调试口径）。
  4. 频谱里总有 160 kHz 干涉——变一下接线、逐根换同轴电缆试：电缆阻抗/质量有问题会在整条线路产生共振，换完看干涉信号怎么变即可判定来源（211 同经验，T48）。结论：线缆是器件，不是配件。
  5. 光纤器件返修——二合一光纤首批不合用需重新定制，1948 nm 台尾纤断寄回厂家，期间"找信号"整条工作被迫暂停（L2-2）。结论：接口规格、长度、余量、保护方案写进采购单，并留备件。

小结

光机电集成没有"差不多"：光学裕量吃紧时最先崩的是机械设计公差，电气噪声超标时最先怀疑的往往是光路没对准，机械"装上去就不好动"时所有前期对光成果都用不上。三条经验留给你我——每域的余量都是别的域的命；先单路打通再扩阵列；可动、可读、可锁死，比精度高更重要。
