声激励频率如何改变横向射流火焰的吹熄极限

王晨2026-11-19

横向射流（jet in crossflow, JICF）火焰是燃气轮机、工业燃烧器中常见的一类构型：燃料射流垂直喷入横向来流，形成抬升火焰。当来流流量增大到一定程度，火焰会突然熄灭——这个临界点就是吹熄极限（blow-off limit），它直接决定燃烧器的稳定工作范围。

如果能用外部手段主动推迟或提前吹熄，就实现了燃烧的主动控制。这正是我们关心的问题：外加声激励，吹熄极限会往哪边移动？跟激励频率有什么关系？ 最近的一组实验给出了一个很有意思的答案。

方法：把"熄没熄"变成一条曲线

火焰探测器信号：火焰探测器输出一个与火焰发光强度相关的电流信号（mA），火焰稳定时信号高、熄灭时跌到基线。我们用 20 Hz 采集。

有火占比 D(Q)：对每个一级空气流量 Q，统计探测器电流 ≥ 4.02 mA 的时间占比，得到"有火占比" D(Q)。流量低时火焰稳定（D ≈ 1），流量升到临界点火焰开始站不住、D 掉到 0。

高斯 CDF 拟合：D(Q) 随 Q 的下降呈 S 形，用高斯累积分布函数拟合：

$$D(Q)=\frac{1}{2}\mathrm{erfc}\left(\frac{Q-\mu}{\sqrt{2}\sigma}\right)$$

两个参数各有明确的物理含义：μ = 熄火点（有火占比降到 50% 的一级空气流量，μ 越大火焰越耐吹）；σ = 转捩宽度（从"稳定有火"到"完全熄火"的过渡有多陡，σ 越大熄得越"拖泥带水"）。

实验：声激励怎么加

燃烧台是一套横向射流装置，一级空气从低到高逐点扫描，二级燃料（甲烷/乙烯）保持点火。声激励通过激励空气路注入，用信号发生器设定频率和幅值。每个流量点稳定后采集火焰信号，得到一条 D(Q) 曲线；换一个激励频率再扫一遍，就得到一组可对比的吹熄曲线。

结果：频率越高，火焰越难吹熄

我们测了无激励基准和 175 / 200 / 225 / 250 Hz 四种激励频率。

无激励 vs 175 Hz：低频促熄

175 Hz 激励时 μ = 845 SLM，比无激励的 874 SLM 提前了约 28 SLM——175 Hz 的声激励让火焰更容易被吹熄。

无激励 vs 200 Hz：高频反转

到了 200 Hz，方向反过来了：μ = 907 SLM，比无激励推迟了约 34 SLM，火焰更难吹熄。从"促熄"变成了"稳燃"。

225 Hz vs 250 Hz：稳燃继续增强

225 Hz 的 μ ≈ 915 SLM，250 Hz 的 μ ≈ 927 SLM，仍然单调上升，没有回头。

讨论：这个频率选择性从哪来

把五个工况串起来：

激励频率熄火点 μ (SLM)
无激励874
175 Hz845
200 Hz907
225 Hz915
250 Hz927

从 175 Hz 到 250 Hz，μ 单调上升。一个自然的解释是：横向射流火焰的稳定性与剪切层不稳定性的频率响应有关——某个频率范围内的激励恰好增强了火焰根部对来流扰动的抵抗，而更低的 175 Hz 反而促进了卷吸与掺混、加速吹熄。这与脉冲横流（pulse crossflow）理论里"激励频率接近剪切层自然频率时火焰响应最强"的图像一致。

小结与下一步

目前得到的一条清晰规律是：175 Hz 促熄，200 Hz 起转为稳燃，且频率越高吹熄极限越高。下一步计划：① 在 175~250 Hz 之间加密频率点，把"频率—吹熄极限"曲线画完整；② 结合 PIV 测速度场与混合分数，把频率响应和剪切层机理对上，验证上面的猜想。
