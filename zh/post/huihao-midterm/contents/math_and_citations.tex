\section{TDLAS测量原理}

可调谐二极管激光吸收光谱（Tunable Diode Laser Absorption Spectroscopy，简称TDLAS）技术是一种基于分子光谱吸收的非侵入式光学测量方法，其基本原理可追溯至比尔-朗伯（Beer-Lambert）定律。

\subsection{比尔-朗伯定律}

当频率为$\nu$的单色激光穿过长度为$L$的均匀气体介质时，若激光光子能量与待测气体分子的某一吸收跃迁能级差相匹配，部分激光将被气体分子吸收。设入射激光光强为$I_0$，透射激光光强为$I$，则两者之间的关系由比尔-朗伯定律描述：
\begin{equation}
	\left(\frac{I}{I_0}\right)_\nu = \exp\left[-\int_0^L \alpha(l,\nu) \cdot dl\right] = \exp[-k_\nu L]
	\label{eq:beer_lambert}
\end{equation}
其中$\alpha(l,\nu)$为待测体系在吸收路径上$l$处、频率为$\nu$的吸光度系数，$k_\nu$为吸收系数。在实际测量中，常定义吸光度$\text{Abs}_\nu$为：
\begin{equation}
	\text{Abs}_\nu = -\ln\left(\frac{I}{I_0}\right)_\nu = \int_0^L \alpha(l,\nu) \cdot dl
	\label{eq:absorbance}
\end{equation}

对于均匀介质，吸光度可简化为：
\begin{equation}
	\text{Abs}_\nu = P \cdot X \cdot S(T) \cdot L \cdot \phi(\nu - \nu_0)
	\label{eq:absorbance_uniform}
\end{equation}
其中：$P$为气体总压（atm）；$X$为待测组分的摩尔分数；$S(T)$为跃迁线强（cm$^{-2}$/atm），是温度$T$的强函数；$L$为吸收光程（cm）；$\phi(\nu - \nu_0)$为归一化线型函数（cm），满足$\int_{-\infty}^{+\infty} \phi(\nu - \nu_0) \dd\nu = 1$。

对式\eqref{eq:absorbance_uniform}在整个波数范围内积分，可得谱线的积分吸光度$A$：
\begin{equation}
	A = \int_{-\infty}^{+\infty} \text{Abs}_\nu \cdot \dd\nu = P \cdot X \cdot S(T) \cdot L
	\label{eq:integrated_absorbance}
\end{equation}

\subsection{谱线强度与温度的关系}

分子吸收光谱的谱线强度$S(T)$是温度的函数，其与温度$T$的关系可由以下公式描述：
\begin{equation}
	S(T) = S(T_0) \frac{Q(T_0)}{Q(T)} \frac{T_0}{T} \exp\left[-\frac{hc E''}{k}\left(\frac{1}{T} - \frac{1}{T_0}\right)\right] \times \left[\frac{1-\exp(-hc\nu_0/kT)}{1-\exp(-hc\nu_0/kT_0)}\right]
	\label{eq:line_strength}
\end{equation}
其中：$h$为普朗克常数（$6.626 \times 10^{-34}~\text{J}\cdot\text{s}$）；$c$为真空中光速（$2.998 \times 10^{10}~\text{cm/s}$）；$k$为玻尔兹曼常数（$1.381 \times 10^{-23}~\text{J/K}$）；$T_0$为标准参考温度（通常取296 K）；$E''$为吸收跃迁的低态能级能量（cm$^{-1}$）；$\nu_0$为跃迁中心频率（cm$^{-1}$）；$Q(T)$为分子的配分函数，表示分子在各能级上的统计分布。

对于大多数红外波段的分子跃迁，$hc\nu_0 \gg kT$，因此式\eqref{eq:line_strength}中的方括号项通常近似为1。谱线强度随温度的升高呈指数增长或衰减，具体取决于$E''$的大小——高$E''$的谱线（高温峰）随温度升高强度增大，低$E''$的谱线（低温峰）随温度升高强度减小。

\subsection{线型函数}

式\eqref{eq:absorbance_uniform}中的线型函数$\phi(\nu - \nu_0)$描述了谱线在频率域的形状，其归一化条件为$\int_{-\infty}^{+\infty} \phi(\nu - \nu_0) \dd\nu = 1$。在燃烧诊断中，主要的线型展宽机制包括：

\textbf{高斯展宽（多普勒展宽）}：由气体分子的热运动引起，其线型函数为高斯函数：
\begin{equation}
	\phi_G(\nu) = \frac{2}{\Delta \nu_G} \sqrt{\frac{\ln 2}{\pi}} \exp\left[-4\ln 2 \left(\frac{\nu - \nu_0}{\Delta \nu_G}\right)^2\right]
	\label{eq:gaussian}
\end{equation}
其中多普勒半高全宽$\Delta \nu_G$为：
\begin{equation}
	\Delta \nu_G = \nu_0 \sqrt{\frac{8kT \ln 2}{mc^2}} = 7.1623 \times 10^{-7} \nu_0 \sqrt{\frac{T}{M}}
	\label{eq:doppler_width}
\end{equation}
其中$m$为分子质量，$M$为分子量。

\textbf{洛伦兹展宽（碰撞展宽）}：由分子间的碰撞引起，其线型函数为洛伦兹函数：
\begin{equation}
	\phi_L(\nu) = \frac{1}{\pi} \frac{\Delta \nu_L/2}{(\nu - \nu_0)^2 + (\Delta \nu_L/2)^2}
	\label{eq:lorentzian}
\end{equation}
其中碰撞展宽半高全宽$\Delta \nu_L$与压力$P$的关系为：
\begin{equation}
	\Delta \nu_L = P \sum_i X_i \cdot 2\gamma_{i}(T_0) \left(\frac{T_0}{T}\right)^{n_i}
	\label{eq:lorentz_width}
\end{equation}
其中$\gamma_i$为第$i$种碰撞配偶体的碰撞展宽系数，$n_i$为其温度指数。

在常压高温火焰中（如1 atm，2000 K），多普勒展宽与碰撞展宽量级相当，因此必须采用\textbf{Voigt线型}——即高斯函数与洛伦兹函数的卷积：
\begin{equation}
	\phi_V(\nu) = \int_{-\infty}^{+\infty} \phi_G(\nu') \phi_L(\nu - \nu') \dd\nu'
	\label{eq:voigt}
\end{equation}
Voigt线型没有解析表达式，通常采用数值方法进行快速计算。

\subsection{双线玻尔兹曼测温法}

由式\eqref{eq:integrated_absorbance}可知，对于同一种分子在同一压力、同一条光程路径上的两条吸收谱线（分别记为谱线1和谱线2），其积分吸光度之比为：
\begin{equation}
	\frac{A_1}{A_2} = \frac{S_1(T)}{S_2(T)}
	\label{eq:ratio_area}
\end{equation}
这表明，两条谱线的积分吸光度之比仅取决于温度$T$，而与气体浓度、压力、光程无关。将式\eqref{eq:line_strength}代入上式，可得：
\begin{equation}
	\frac{A_1}{A_2} = \frac{S_1(T_0)}{S_2(T_0)} \cdot \exp\left[-\frac{hc}{k} \frac{(E''_1 - E''_2)}{T} + \frac{hc}{k} \frac{(E''_1 - E''_2)}{T_0}\right]
	\label{eq:boltzmann_ratio}
\end{equation}
对式\eqref{eq:boltzmann_ratio}取自然对数并整理，可得温度的显式表达式：
\begin{equation}
	T = \frac{\frac{hc}{k} (E''_2 - E''_1)}{\ln\left(\frac{A_1}{A_2}\right) - \ln\left(\frac{S_1(T_0)}{S_2(T_0)}\right) + \frac{hc}{k} \frac{E''_1 - E''_2}{T_0}}
	\label{eq:temperature_explicit}
\end{equation}
这就是\textbf{双线玻尔兹曼测温法}的基本原理。


\section{TDLAS光学测量硬件}

\subsection{激光源与控制器}

激光器选用NTT NLK1B5GAAA型蝶形封装DFB激光器，中心波长1398 nm，输出功率$>$10 mW。激光器安装于定制亚克力透明保护盒内，并固定在光学平台上，移动或接线操作前，必须确认固定螺丝已拧紧，光纤连接器无应力拉扯；驱动模集成TEC温度控制回路与低噪声电流驱动回路。

\textbf{TEC温度控制原理}：激光二极管的激射波长对温度高度敏感，典型温度调谐系数约为$0.1~\text{nm/K}$（对应约$0.5~\text{cm}^{-1}\text{/K}$）。温度每变化$0.1^\circ$C，波长漂移约0.01 nm，足以使吸收峰偏离目标位置半个线宽。因此，精确的温度稳定是波长锁定的前提。

TEC控温系统的工作原理：TEC模块基于佩尔捷效应（Peltier Effect），通过改变流过PN结的电流方向实现制冷或加热。LDC-3900内部集成PID反馈控制回路，以热敏电阻的阻值（与温度呈负相关）为反馈信号，与设定温度对应的目标阻值进行比较，误差信号经PID运算后驱动TEC模块工作。该系统的温度稳定度优于$\pm 0.005^\circ$C，对应波长漂移小于$\pm 0.0005$ nm，远小于吸收谱线的半高宽（$\sim$0.02 nm），满足精密吸收光谱测量对波长稳定性的要求。

\subsection{波长选线与光谱仿真}

激光器的工作波长需精确匹配目标吸收谱线，因此首先需要通过光谱仿真确定最优谱线对。本研究利用实验室自主开发的\textbf{Flame Spectrum仿真平台}（基于HITRAN API接口开发）开展光谱仿真工作。

\subsubsection{仿真设置}

Flame Spectrum平台底层调用HITRAN 2020分子光谱数据库，基于逐线积分（Line-by-Line）方法计算给定温度、压力、光程和组分条件下的理论吸收光谱。仿真参数设置如下：

\begin{itemize}
	\item 波段范围：7150--7160 cm$^{-1}$（覆盖目标水吸收线对及其邻近干扰线）
	\item 温度序列：1500 K、2000 K、2500 K、3000 K（覆盖本研究的全部目标温度范围）
	\item 压力：1 atm（常压平面炉实验条件）
	\item 吸收光程：4 cm（对应火焰直径约40 mm）
	\item 组分：H$_2$O摩尔分数设为5\%（典型甲烷/空气平面炉燃烧产物中H$_2$O浓度水平），N$_2$为平衡气
	\item 仪器展宽：设为0.02 cm$^{-1}$（高斯线型，模拟DFB激光器线宽和标准具响应）
	\item 波长步长：$5 \times 10^{-5}$ cm$^{-1}$（确保每个谱线有足够的采样点用于拟合）
\end{itemize}

仿真输出为各温度条件下H$_2$O吸收光谱的吸光度随波数变化的理论曲线。

\subsection{谱线选择策略}

为了获得高精度的温度测量，谱线对的选择需遵循以下原则：

\begin{enumerate}
	\item \textbf{低态能级差尽可能大}：$\Delta E''$越大，温度灵敏度$\dd R/\dd T$越高，其中$R = A_1/A_2$为面积比。
	\item \textbf{两条谱线波长相近}：便于单次激光扫描同时覆盖两条谱线，避免激光功率漂移和环境变化引入的系统误差。
	\item \textbf{谱线强度适中}：在目标温度范围内两条谱线均具有较强的吸收信号，且不受其他邻近谱线干扰。
	\item \textbf{光谱参数精确已知}：$S(T_0)$和$E''$在HITRAN/HITEMP数据库中准确可靠。
\end{enumerate}

基于仿真结果，最终选定的目标谱线对为：

\begin{itemize}
	\item \textbf{高温峰}：7153.75 cm$^{-1}$，低态能级$E''=2552.9$ cm$^{-1}$
	\item \textbf{低温峰}：7154.35 cm$^{-1}$，低态能级$E''=1789.0$ cm$^{-1}$
\end{itemize}

二者低态能级差$\Delta E'' \approx 763.9$ cm$^{-1}$，在1000--3000 K范围内具有优异的温度灵敏度。

仿真结果揭示了以下关键特征：

\begin{enumerate}
	\item \textbf{谱线强度随温度的变化}：低温峰（7154.35 cm$^{-1}$）在1500 K时强度显著高于高温峰（7153.75 cm$^{-1}$），二者面积比$R$较大；随着温度升高至3000 K，高温峰强度快速增长，低温峰强度相对下降，面积比$R$逐渐趋近于1。该变化趋势验证了所选谱线对在1000--3000 K范围内的温度敏感性。
	
	\item \textbf{干扰峰识别}：在7153.8 cm$^{-1}$处（高温峰高波数侧约0.05 cm$^{-1}$位置）存在一个极弱的相邻干扰峰。该峰在各温度条件下均有出现，其强度随温度升高而略有增加，但始终低于主峰强度的2\%--3\%。该干扰峰源于H$_2$O分子的邻近跃迁线，在常压条件下因碰撞展宽与主峰发生部分重叠。
	
	\item \textbf{谱线重叠程度}：在3000 K高温条件下，由于多普勒展宽和碰撞展宽均增大，两条目标谱线的半高宽分别增至约0.08 cm$^{-1}$和0.09 cm$^{-1}$，二者中心间距约0.60 cm$^{-1}$，约为半高宽的7倍，相互重叠程度较低，可独立拟合。但邻近干扰峰（7153.8 cm$^{-1}$）距离高温峰仅0.05 cm$^{-1}$，在拟合过程中不可忽略——若采用标准双峰模型而不考虑该弱峰，会导致高温峰积分面积被高估约3\%--5\%，进而使温度反演结果偏低约2\%--3\%（在2500 K工况下）。因此，在实际数据处理中需采用三峰模型或适当缩小拟合窗口边界。
\end{enumerate}

\subsection{波长锁定流程}

基于上述仿真确定的谱线对，激光器的激射波长需精确锁定至目标位置。波长由温度和电流共同决定，温度调谐系数约为$0.5~\text{cm}^{-1}/^\circ\text{C}$（粗调），电流调谐系数约为$0.02~\text{cm}^{-1}/\text{mA}$（精调）。波长锁定的具体流程如下：

\begin{enumerate}
	\item \textbf{温度粗扫}：将激光器电流固定在一个中间值（$I=50$ mA），温度从$10^\circ$C至$30^\circ$C以$0.5^\circ$C步长步进扫描，将观测到的吸收峰位置与仿真光谱进行比对，初步定位目标波长对应的温度区间。
	
	\item \textbf{电流精调与锁定}：在粗扫确定的温度附近（15--$16^\circ$C范围内），以$0.05^\circ$C为步长微调温度，同时以0.1 mA为步长微调电流，观察目标水吸收线的位置和强度变化，直至观测到的吸收峰位置与HITRAN仿真结果的偏差小于0.005 cm$^{-1}$。
	
	\item \textbf{锁定验证}：在锁定温度/电流条件下连续采集30分钟吸收光谱，每隔1分钟记录一次吸收峰的峰值位置和面积，计算波长漂移的标准差。若标准差小于0.001 cm$^{-1}$（对应温度波动$<$0.01$^\circ$C），则确认波长锁定有效。
\end{enumerate}

经过上述流程的反复调谐与验证，最终锁定工作点为\textbf{$T=15.6^\circ$C，$I=50.9$ mA}。在该工作点下，激光器输出中心波长稳定在\textbf{1397.824 nm}（真空波数对应7154.35 cm$^{-1}$），扫描电流范围（40--60 mA，对应波长扫描范围约$\pm$0.3 nm）可完整覆盖7153.5至7155.0 cm$^{-1}$区间，同时捕获高温峰（7153.75 cm$^{-1}$）和低温峰（7154.35 cm$^{-1}$）。

\section{光路搭建}

激光输出经FC/APC光纤跳线出射，首先经过\textbf{1×3光纤分束器}将光线分为三路，分别服务于不同的功能需求：

\begin{enumerate}
	\item \textbf{测量光路（主光路，占比约80\%）}：作为测量光束穿过待测火焰区域，携带吸收光谱信息后被光电探测器接收。该路光是整个TDLAS系统的核心信号通道。
	\item \textbf{背景光路（参考光路1，占比约10\%）}：不经待测区域直接进入探测器，用于实时监测激光器出射光强的波动，作为吸收光谱计算的背景参考，以消除激光器自身功率漂移对测量精度的影响。
	\item \textbf{标准具光路（参考光路2，占比约10\%）}：经过自行研制的光纤干涉器件（详见下文“标准具制作”小节），产生等波数间隔的干涉条纹，用于后续的光谱波数标定。
\end{enumerate}

在完成分光后，测量光路首先经过两个镀金反射镜（保护银膜，反射率$>$98\%@1.4$\mu$m）。采用双反射镜组合可实现X-Y二维平移调节，确保光束在穿过待测火焰区域时始终保持水平，且光路与光学平台边缘平行，便于后续光路元件的装调。

光束经反射镜调整指向后，进入\textbf{光束扩展与缩束系统}。光纤出射的激光束腰直径约为5 mm，发散角较大，直接用于火焰测量时空间分辨率不足。本研究采用伽利略型望远镜结构实现光束压缩：组合透镜依次为凹透镜（$f=-25$ mm）和两组凸透镜（$f=75$ mm，$f=150$ mm）。凹透镜首先将光束进一步发散，随后由第一凸透镜初步汇聚，第二凸透镜完成最终聚焦。该设计可在不引入额外球差的前提下将光斑压缩至目标尺寸。经红外CCD相机（FLIR Boson 640，响应波段0.9--2.5$\mu$m）监测确认，焦点处光斑直径约\textbf{0.8 mm}，足以解析厚度约2--3 mm的火焰内部温度梯度。光束经过待测火焰区域后，由另一端的光电探测器接收，完成测量光路的信号采集。

\subsection{标准具制作}

传统的法布里-珀罗标准具（Fabry-Pérot Etalon）由两块平行高反镜组成，利用多光束干涉原理产生等光学频率间隔的透射峰，是TDLAS系统中实现波数标定的核心器件。然而，传统标准具在使用过程中需要将激光束严格垂直入射至标准具镜面，光路调节复杂且对机械振动敏感，每次实验前均需耗费大量时间进行角度校准。

为简化实验操作、提高系统集成度，本研究自行研制了一种基于光纤的\textbf{光纤干涉器件}，用于替代传统F-P标准具。其原理如图~\ref{fig:etalon_principle}所示：利用1×2光纤分束器将入射激光分为两路，两路光纤长度不同，存在固定的光程差$\Delta L$。两路光经合束器重新汇合后，由于两束光的光程差固定，在输出端会形成稳定的干涉，其干涉条纹的频率间隔由光程差$\Delta L$唯一确定：
\begin{equation}
	\Delta \nu = \frac{c}{\Delta L}
\end{equation}
其中$c$为光速，$\Delta L$为两路光纤的光程差。设计光程差$\Delta L \approx 20$ cm时，对应的频率间隔$\Delta \nu \approx 1.5$ GHz（约0.05 cm$^{-1}$），可满足TDLAS波长扫描的标定需求。

与传统F-P标准具相比，该光纤干涉方案具有以下优势：第一，全光纤结构无空间光路，无需光学调节，即插即用；第二，光纤器件对振动不敏感，长期稳定性优异；第三，体积小巧，可集成于实验光路中不额外占用空间。

然而，简单的分光合束方案存在一个关键问题：普通光纤分束器不具备方向选择性，在将光一分为二再合二为一的过程中，两路光纤内部会产生反向传输的反射光，导致输出端同时存在正向干涉信号和反向传输的杂散光，使干涉信号被淹没。为解决这一问题，本设计在每一路光纤支路上均串入\textbf{光纤环形器（Fiber Circulator）}。环形器的端口特性保证了光信号沿确定方向单向传输——光从端口1进入，由端口2输出；从端口2返回的光由端口3输出，不会反向进入端口1。通过环形器的引入，彻底消除了反向传输光对正向干涉信号的干扰，使干涉器具有了明确的输入端和输出端。

此外，由于光纤干涉的稳定性高度依赖两路光程差的恒定，即使温度变化导致光纤热胀冷缩引入微米级长度变化，也会导致干涉条纹的漂移。因此，在器件调试完成、确认干涉信号稳定后，使用光学胶将所有光纤连接器及尾纤段固定在铝制基板上，确保光程差不受外界振动和温度波动的影响。

\subsection{信号探测与跨阻放大器}

信号探测与放大链路是TDLAS系统中决定信噪比和测量精度的关键环节。本项目的探测系统分为两个阶段：前期采用商业探测器完成单通道验证实验，后期根据多通道并行测量的需求自行研制探测器模块。

初始阶段，光电探测器采用Thorlabs PDA20CS2型InGaAs放大接收器，响应波段覆盖700--2200 nm，内置可切换增益（50/150 dB$\Omega$），无需外置放大器即可直接输出放大后的电压信号。该探测器在本项目初期的单通道验证实验中表现良好，足以满足10 kHz扫描频率下的吸收光谱采集需求。

然而，随着后续实验向高空间分辨率方向推进，计划采用1分16光纤束实现16通道并行光谱采集，每个通道需要独立的光电探测器和跨阻放大器（TIA）。继续使用Thorlabs商业探测器将面临两个问题：一是16通道的设备成本过高（单通道售价$\sim$\$1000）；二是各通道之间的一致性难以保证（不同探测器之间存在增益差异）。

\section{TDLAS数据处理}

基于上述TDLAS测量原理，本节详细介绍从原始采集信号到最终温度场输出的完整数据处理流程。

\subsection{原始信号预处理模块}

预处理模块包含两个核心功能。

第一，多周期平均——以激光器的扫描同步触发信号（TTL）为基准，截取单个扫描周期的原始数据，对300个连续周期的数据进行整体平均，消除随机白噪声（信噪比可提升10倍）。

第二，背景基线扣除——采用非吸收区域多项式拟合方法，选取扫描波数范围的两端（7153.3--7153.5 cm$^{-1}$和7154.8--7155.0 cm$^{-1}$），这些波段无H$_2$O强吸收，利用三阶多项式拟合基线，再对整个扫描范围内的原始信号进行归一化，从根本上避免了“负峰”错误。此步骤的物理依据是：式\eqref{eq:beer_lambert}中基线$I_0$应为无吸收时的激光光强，准确扣除基线是获得精确积分吸光度$A$的前提。

\subsection{FSR波数转换模块}

\subsubsection{非线性问题的来源}

在TDLAS测量中，激光器通常采用电流调谐方式实现波长扫描——通过施加正弦波或三角波驱动电流，使激光器输出波长在目标吸收线附近往复扫描。然而，由于激光器在工作过程中温度会发生非线性变化（热电制冷器的响应延迟、环境温度波动等因素），导致激光波长随时间的变化率并非恒定，而是呈非线性漂移。因此，原始采集卡记录的信号在时间域上是等间隔采样的，但在波数域上却是非均匀分布的。若直接使用等间隔假设进行数据处理，将导致吸收峰位置偏移、线型畸变，进而使温度反演产生显著误差。

为了将信号校正为线性波数分布，需要借助一个提供等光学频率间隔基准的参考信号——这通常由法布里-珀罗标准具（Fabry-Pérot Etalon）的等间距干涉条纹实现。通过将吸收光谱的时域采样点映射到标准具的等波数间隔干涉峰上，可以实现从“非均匀波数轴”到“均匀波数轴”的精确转换。

\subsubsection{FSR刻度值计算}

在采集到标准具干涉信号后，首先需要通过峰值检测确定各干涉峰的精确位置。具体处理流程如下：

\begin{enumerate}
	\item \textbf{峰检测}：利用Scipy的\verb|find_peaks|函数，设置最小高度阈值和最小间距，初步识别标准具透射峰的位置$p_0, p_1, \ldots, p_{N-1}$。
	
	\item \textbf{峰值位置精修}：由于实验采集的信号存在噪声，初步检测的峰位置可能存在微小偏差。为消除这一误差，对每个检测到的干涉峰附近的局部信号进行二次多项式拟合，以拟合曲线的顶点位置作为峰的精确位置。这一处理可将峰位置定位精度提升至亚像素级别。
	
	\begin{figure}[!htp]
		\centering
		\includegraphics[width=0.7\textwidth]{image25.png}
		\caption{标准具干涉信号峰值检测与二次拟合精修}
		\label{fig:etalon_peaks_fit}
	\end{figure}
	
	\item \textbf{FSR刻度生成}：赋予每个干涉峰一个线性刻度值$s_i = i$（$i = 0, 1, 2, \ldots, N-1$）。由于相邻干涉峰之间的波数间隔相等，这一线性刻度在波数域上对应于等间距的“频率尺”。
	
	\item \textbf{插值映射}：对于原始信号中的每一个采样点（全局索引），根据其与相邻峰的位置关系，采用分段线性插值方法计算其对应的FSR刻度值：
	\begin{equation}
		s(x) = s_i + \frac{x - p_i}{p_{i+1} - p_i} \cdot (s_{i+1} - s_i)
	\end{equation}
	对于首尾边界区域，采用一阶线性外推，斜率取前三个峰（或后三个峰）的均值。
\end{enumerate}

图~\ref{fig:fsr_scale_mapping}展示了每个采样点索引与对应的FSR刻度值之间的映射关系，可见该映射为单调递增函数，有效反映了激光器波长扫描的非线性特征。

\subsubsection{吸收峰定位与波数转换}

在完成FSR刻度生成后，需对吸收光谱进行相同索引体系下的处理：

\begin{enumerate}
	\item \textbf{背景扣除}：采用非吸收区域多项式拟合方法扣除基线，获得归一化的吸收光谱。
	
	\item \textbf{吸收峰检测}：在归一化吸收光谱中，利用\verb|find_peaks|函数检测两个目标吸收峰的位置，同样采用局部二次拟合对峰位置进行亚像素精修，获取吸收峰对应的全局索引值。
	
	\item \textbf{索引匹配}：由于标准具信号与吸收光谱信号由同一数据采集卡同步采集，两者的采样点索引一一对应。因此，吸收峰在原始信号中的全局索引可直接用于查询该位置对应的FSR刻度值。
	
	\item \textbf{波数赋值}：根据HITRAN数据库，为两个吸收峰赋予真实波数值（$\nu_1$和$\nu_2$）。在已知两个吸收峰的波数和对应FSR刻度的条件下，建立波数与FSR刻度之间的线性关系：
	\begin{equation}
		\nu(s) = \nu_1 + k \cdot (s - s_1)
	\end{equation}
	其中斜率$k = (\nu_2 - \nu_1) / (s_2 - s_1)$，表示单位FSR刻度对应的波数变化量。
	
	\item \textbf{全谱波数转换}：利用上述线性关系，将原始信号中每一个采样点的FSR刻度值$s_i$转换为对应的波数$\nu_i$，即完成从“时域/索引域”到“波数域”的精确映射。
\end{enumerate}

图~\ref{fig:wavenumber_conversion_result}展示了波数转换完成后的吸收光谱，横坐标已从原始的采样点索引转换为精确的波数（cm$^{-1}$）。转换后的光谱在波数域上呈现出均匀分布，两条目标吸收峰的位置与HITRAN数据库的理论值高度吻合，验证了FSR波数转换方法的准确性和可靠性。

\subsubsection{核心代码实现}

以下代码实现了FSR刻度计算与波数转换的核心函数。

\begin{lstlisting}[language=Python, caption=FSR刻度计算与波数转换核心函数, label=lst:fsr_core]
	import numpy as np
	from scipy.interpolate import interp1d
	
	# 1. 峰检测（极值法）
	def minmax(y, delta):
	peaks = []
	mn, mx = np.inf, -np.inf
	mxpos = np.nan
	lookformax = True
	for i, val in enumerate(y):
	if val > mx:
	mx = val
	mxpos = i
	if lookformax and val < mx - delta:
	peaks.append(mxpos)
	mn = val
	lookformax = False
	elif not lookformax and val > mn + delta:
	mx = val
	mxpos = i
	lookformax = True
	return np.array(peaks)
	
	# 2. 二次拟合精修峰位置
	def refine_peak_position(y, rough_peaks, window=5):
	refined = []
	for p in rough_peaks:
	s, e = max(0, p-window), min(len(y)-1, p+window)
	x, y_fit = np.arange(s, e+1, dtype=float), y[s:e+1]
	a, b, _ = np.polyfit(x, y_fit, 2)
	refined.append(-b / (2*a))
	return np.array(refined)
	
	# 3. 计算FSR刻度
	def compute_fsr_scale(y, delta=0.005):
	rough = minmax(y, delta)
	refined = refine_peak_position(y, rough)
	fsr_order = np.arange(len(refined), dtype=float)
	interp = interp1d(refined, fsr_order, kind='linear', fill_value='extrapolate')
	return interp(np.arange(len(y))), refined
	
	# 4. 波数转换（线性标定）
	def convert_wavenumber(fsr_scale, peak1_idx, peak2_idx, nu1, nu2):
	s1, s2 = fsr_scale[peak1_idx], fsr_scale[peak2_idx]
	k = (nu2 - nu1) / (s2 - s1)
	return nu1 + k * (fsr_scale - s1)
\end{lstlisting}

上述函数实现了FSR波数转换的核心功能，已在实验数据上验证，转换后吸收峰位置与HITRAN参考值偏差小于0.005 cm$^{-1}$。

\subsection{Voigt双峰拟合模块}

波数转换完成后，需要从实测吸光度光谱中提取目标谱线的积分吸光度$A_1$和$A_2$。由于Voigt线型没有解析表达式，本研究采用非线性最小二乘拟合方法同时拟合两条目标谱线。

模型构建使用LMFIT库的\verb|Model|类，构建复合模型：
\begin{equation}
	y(x) = a_0 x^2 + a_1 x + a_2 + A_1 V(x; \mu_1, \sigma_G, \gamma_L) + A_2 V(x; \mu_2, \sigma_G, \gamma_L)
	\label{eq:voigt_fit_model}
\end{equation}
其中前两项为二次多项式基线，用于补偿光学元件残余反射等引入的缓慢基线变化；$V(x; \mu, \sigma_G, \gamma_L)$为Voigt线型函数，$\mu$为中心波数，$\sigma_G$为高斯展宽参数（与温度相关），$\gamma_L$为洛伦兹展宽参数（与压力相关）。两条谱线的多普勒展宽$\sigma_G$相同（同一温度场），碰撞展宽$\gamma_L$可分别设置但通常设为耦合（同一压力环境）。

初始值智能估计方面，$\mu_1, \mu_2$初始值由HITRAN数据库提供（7153.75，7154.35 cm$^{-1}$），$\sigma_G$初始值由预估温度（2000 K）根据式\eqref{eq:doppler_width}计算，$\gamma_L$初始值由空气展宽系数乘以1 atm估算。权重策略对吸收峰区域（$\pm 3\sigma_G$范围）赋予权重10，基线区域赋予权重1，以优先保证谱线形状的拟合精度。

\subsection{温度反演与场重建模块}

获得两条目标谱线的积分吸光度$A_1$和$A_2$后，根据玻尔兹曼公式进行温度求解。
\begin{equation}
	\frac{A_1}{A_2} = \frac{S_1(T_0)}{S_2(T_0)} \cdot \frac{Q(T_0)}{Q(T)} \cdot \exp\left[-\frac{hc}{k}\frac{(E''_1 - E''_2)}{T}\right]
	\label{eq:boltzmann_implementation}
\end{equation}
在实际求解中，采用牛顿-拉夫逊法快速迭代求解$T$。

核心温度反演代码如列表~\ref{lst:boltzmann}所示。

\begin{lstlisting}[language=Python, caption=玻尔兹曼温度反演核心代码, label=lst:boltzmann]
	import numpy as np
	from scipy.optimize import fsolve
	
	def boltzmann_temperature(A1, A2, E1, E2, S1_0, S2_0, T0=296):
	h = 6.626e-34    # 普朗克常数 [J*s]
	c = 2.998e10     # 光速 [cm/s]
	k = 1.381e-23    # 玻尔兹曼常数 [J/K]
	
	def equation(T):
	ratio_meas = A1 / A2
	ratio_pred = (S1_0 / S2_0) * np.exp(
	-(h*c/k) * (E1 - E2) * (1/T - 1/T0)
	)
	return ratio_meas - ratio_pred
	
	T_solution = fsolve(equation, 1500)[0]
	return T_solution
\end{lstlisting}

温度反演算法的验证采用2600 K和2400 K仿真光谱添加3\%噪声后作为输入，反演温度分别为2626 K和2404 K，偏差约为1\%，验证了代码的准确性（图~\ref{fig:temp_validation}）。
