引言

在实验流体力学中，粒子图像测速（PIV） 与 平面激光诱导荧光（PLIF） 是两种广泛使用的光学测量技术。前者能获得瞬时速度场，后者可捕捉标量（如浓度、温度）的空间分布。如何从大量实验数据中高效提取有物理意义的信息，尤其是分离出真实的涡结构，一直是个挑战。

传统涡量 $\omega = \nabla \times \mathbf{v}$ 无法区分刚体旋转和剪切变形——纯剪切流也具有非零涡量。Liutex 涡识别方法（刘超群教授团队提出）通过特征值分析和坐标旋转，从速度梯度张量中精确提取刚性旋转部分，避免 Q、λ₂ 等传统判据将剪切误判为涡的缺点。

Liutex方法简介

我们基于此理论，开发了一款跨平台、模块化的 GUI 软件，并整理了一套完整的 Liutex 理论文档与示例代码（112-nozzle/3-code/liutex/）。

Liutex 理论基础

基本假设与理论依据

Liutex 理论建立在速度梯度张量的对称/反对称分解之上。

Cauchy-Stokes 分解：任意速度梯度张量可分解为对称部分（应变率张量 $\mathbf{S}$）和反对称部分（涡量张量 $\mathbf{\Omega}$）：

$$\nabla\mathbf{v} = \mathbf{S} + \mathbf{\Omega}, \quad \mathbf{S} = \frac{\nabla\mathbf{v} + (\nabla\mathbf{v})^T}{2}, \quad \mathbf{\Omega} = \frac{\nabla\mathbf{v} - (\nabla\mathbf{v})^T}{2}$$

对于二维流场：

$$\mathbf{S} = \begin{bmatrix} u_x & \frac{u_y+v_x}{2} \\ \frac{u_y+v_x}{2} & v_y \end{bmatrix}, \quad \mathbf{\Omega} = \begin{bmatrix} 0 & -\omega/2 \\ \omega/2 & 0 \end{bmatrix}$$

其中 $\omega = v_x - u_y$ 是涡量。问题在于：涡量张量 $\mathbf{\Omega}$ 中的 $\omega$ 同时包含刚体旋转和剪切变形——纯剪切流也具有非零 $\omega$。

Liutex 的核心思想：通过正交旋转（Q 旋转 + P 旋转）将 $\nabla\mathbf{v}$ 变换到唯一的主坐标系，使旋转轴与 $z$ 轴对齐。在主坐标系中，反对称部分被进一步分解为刚性旋转（$R$）和残余剪切（$\varepsilon$）：

$$\nabla\mathbf{V}_\theta = \begin{bmatrix} 0 & -R/2 \\ R/2+\varepsilon & 0 \end{bmatrix} = \underbrace{\begin{bmatrix} 0 & -R/2 \\ R/2 & 0 \end{bmatrix}}_{\text{纯旋转}} + \underbrace{\begin{bmatrix} 0 & 0 \\ \varepsilon & 0 \end{bmatrix}}_{\text{纯剪切}}$$

基本假设：

  1. 不可压缩流：$\nabla \cdot \mathbf{v} = 0$，即 $\operatorname{tr}(\nabla\mathbf{v}) = u_x + v_y = 0$
  2. 二维流场：旋转轴垂直于流动平面，$\mathbf{r} = [0, 0, 1]^T$
  3. 涡量标量不变性：坐标旋转下 $\omega$ 不变，$\omega = R + \varepsilon$
  4. 存在刚性旋转的判据：$\nabla\mathbf{v}$ 有一对共轭复特征值，即 $\lambda_{ci}^2 > 0$

核心公式推导

对于二维不可压缩流场 $(u, v)$：

速度梯度张量：

$$\nabla \mathbf{v} = \begin{bmatrix} u_x & u_y \\ v_x & v_y \end{bmatrix}$$

特征值虚部平方（由 $\det(\nabla\mathbf{v} - \lambda\mathbf{I}) = 0$ 展开，代入 $\operatorname{tr}=0$）：

$$\lambda_{ci}^2 = u_x v_y - u_y v_x$$

涡量：$\omega = v_x - u_y$

由旋转后的规范形式，建立两个关系式：

$$\omega = R + \varepsilon, \quad \lambda_{ci}^2 = \frac{R}{2}\left(\frac{R}{2} + \varepsilon\right) = \frac{R^2}{4} + \frac{R\varepsilon}{2}$$

消去 $\varepsilon$ 得 Liutex 强度：

$$\boxed{R = |\omega| - \sqrt{\omega^2 - 4\lambda_{ci}^2}}$$

涡量 RS 分解：$|\omega| = R + S$，$S = \sqrt{\omega^2 - 4\lambda_{ci}^2}$，满足 $\omega^2 = R^2 + S^2$。

Python 实现

import numpy as np

def liutex_2d(U, V):
    ux, uy = np.gradient(U, axis=1), np.gradient(U, axis=0)
    vx, vy = np.gradient(V, axis=1), np.gradient(V, axis=0)
    omega = vx - uy
    lam2 = np.maximum(ux * vy - uy * vx, 0.0)
    omega_abs = np.abs(omega)
    disc = np.maximum(omega_abs**2 - 4 * lam2, 0.0)
    R = (omega_abs - np.sqrt(disc)) * np.sign(omega)
    S = np.sqrt(disc)
    return R, S, np.sqrt(lam2)

完整代码与文档见 112-nozzle/3-code/liutex/。

软件主要功能

1. 多格式数据加载

  • PIV：支持 DaVis 输出的标准 .txt 文件（包括 #DaVis 头格式）以及 TECPLOT 风格的 .dat 文件。自动识别格式，无需手动指定。
  • PLIF：读取 TIFF 图像序列，并提供边缘保持滤波、阈值掩膜、模糊增强等预处理选项，便于与速度场叠加显示。
  • PLIF 原始数据：支持 Photron FASTCAM 高速相机原始 TIFF 序列，自动解析 .cihx 元数据文件，提取相机参数（分辨率、帧率、快门速度、位深等），并自动处理高位存储的有效位深（如 12/14 bit 存储在 16 bit TIFF 高位）。
  • Bin 平均：可自定义下采样倍数，降低数据量并过滤高频噪声。

1.5 PLIF 原始图像独立浏览

软件内置了独立的 PLIF 原始图像浏览对话框，可脱离 PIV 数据单独使用：加载 Photron 原始文件夹后，支持帧序列浏览（播放/暂停/逐帧）、帧级统计信息（最小值、最大值、均值、标准差），以及当前帧导出为 PNG 图片。

PLIF 图像上支持点击选点做 FFT 频谱分析，提取该像素在所有时间帧上的强度序列进行傅里叶变换。

2. 流场物理量计算

基于速度场 (u, v) 自动计算：

  • 基础量：合速度、涡量、散度、速度梯度分量 $ |\nabla u|, |\nabla v| $
  • Liutex：严格遵循刘超群教授的公式，输出纯旋转强度 \(R\)、剪切贡献 \(S\) 以及局部旋转角速度 $\lambda_{ci}$

计算核心完全与界面分离，可单独调用，便于批处理或嵌入其它脚本。

3. 可视化与交互

  • 使用 Matplotlib 嵌入 PyQt6 界面，利用 轮廓填色（contourf） 显示标量场，并可叠加 速度矢量（quiver） 和 流线（streamline）。
  • PLIF 叠加：将处理后的 PLIF 标量场以半透明形式覆盖在速度场之上，直观显示标量与流动结构的耦合。
  • 实时动画：支持播放/暂停、拖动滑块浏览序列帧。
  • 交互工具栏：Matplotlib 内置导航工具栏，支持缩放、平移、保存图片等操作。
  • 可随时将当前显示的标量场数据导出为 .npy 文件，便于后续分析。

4. 单点 FFT 分析

在流场图上点击任意位置，软件自动提取该点所有时间步的物理量（如 Liutex、涡量）序列，并进行 FFT 变换，绘制单边幅值谱。这对于识别流动中的周期性特征（如尾涡脱落频率）非常实用。

5. 独立的图像叠加

新增了独立的**“图像叠加”**对话框，可从 PIV 数据或 PLIF 数据中自由选取任意两张图像进行叠加比较：

  • PIV 标量场：可从合速度、涡量、散度、Liutex 等六个物理量中任选，支持帧序号切换。
  • PLIF 图像：支持 TIFF 文件直接加载，或通过原始文件夹选择单帧。
  • 叠加图通过透明度滑杆实时调节两张图的混合比例，方便对比标量场与流动特征的空间相关性。
  • 任意组合：支持 PIV+PIV、PLIF+PLIF、PIV+PLIF 两两叠加，无限制。

关键技术点

  • Liutex 求解精度：在梯度计算中对速度场进行了 NaN/Inf 过滤，并采用中心差分；对坐标间距使用了高精度浮点，避免因 float32 舍入导致网格不等距。
  • 坐标兼容性：自动识别并转置 PIV 输出格式，确保与 Matplotlib 的 contourf、streamplot 期望一致；流线绘制前使用 linspace 强制生成绝对等距坐标，避免因浮点误差导致的 'x' values must be equally spaced 错误。
  • 内存优化：所有数组均以 float32 存储，数百帧数据仍可流畅操作。
  • PLIF 原始位深处理：自动解析 Photron .cihx XML 元数据，识别 <effectiveBit>（有效位深，如 12 bit）和 <side>（高位或低位存储）。对于高位存储的原始 TIFF，自动执行 >> (bit_depth - effective_depth) 右移，将高位有效数据还原到低位，确保物理值与相机像素值对应。
  • PLIF 原始数据按需加载：原始文件夹模式下只解析 .cihx 元数据和 TIFF 文件列表，不一次性加载全部帧；切换帧时才读取单张图像并缓存，大幅降低内存占用和加载延迟。
  • 叠加性能优化：使用 cv2.resize 统一图像尺寸后直接 RGBA 混合，避免 scipy.griddata 在跨坐标网格插值时的 O(N²) 瓶颈。

运行环境与依赖

  • Python ≥ 3.9
  • PyQt6
  • Matplotlib
  • NumPy, SciPy
  • OpenCV (用于 PLIF 增强与叠加对齐)
  • 可选：imageio、tifffile（多格式 TIFF 读取回退）

可通过 pip install -r requirements.txt 一键安装依赖。软件已在 Linux (Fedora) 下测试通过，Windows/macOS 理论上也可运行。

快速上手

  1. 下载压缩包 piv_plif_loader
  2. 运行 python app.py
  3. 点击 “加载 PIV 序列” 选择 DaVis 导出的 .txt 或 .dat 文件（支持多选）
  4. 可选：“加载 PLIF 序列” 选择 TIFF 图像
  5. 在下拉框中选择要显示的物理量（涡量、散度、Liutex 等）
  6. 勾选 quiver 或 streamline 叠加矢量或流线
  7. 使用工具栏缩放/平移图像，或将数据保存为 .npy
  8. 点击 “在流场上选点” 后在图像上单击，即可查看该点的 FFT 频谱
  9. 点击 “图像叠加” 打开独立叠加窗口，自由组合任意两张图像进行对比
