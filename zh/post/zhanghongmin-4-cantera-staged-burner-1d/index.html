轴向分级燃烧器是 crossflow 系列实验的仿真对象之一。本文记录用 Cantera 跑一维火焰/燃烧仿真的入门过程：先把环境和官方算例跑通，再逐步换成自己的燃料体系与工况。

Cantera 下载与安装

Cantera 以"库 + 脚本"的方式运行，可以在多种软件中调用。我的环境是在 PyCharm 的终端里直接安装：

pip install numpy scipy matplotlib
pip install cantera -i https://pypi.tuna.tsinghua.edu.cn/simple

等待安装完成后即可在 Python 中 import cantera。
