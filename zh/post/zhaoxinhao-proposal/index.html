赵鑫浩开题报告

2026-10-12

一、立论依据

1、课题来源、选题依据和立论背景

本课题来源于导师主持的科研项目，面向高黏度料液（糖浆、浓缩果汁、蛋白液等食品料液）在喷雾干燥与造粒过程中的雾化需求。雾化是液体燃料燃烧、喷雾干燥、粉体造粒等工业过程的首要环节，其本质是通过喷嘴把连续液柱破碎为大量细小液滴，以成倍增大气液接触面积，从而强化传热传质。液滴粒径及其分布直接决定了干燥速率、产品质量与能耗，是雾化技术的核心指标。

常规雾化方式中，压力旋流雾化依靠液体自身压力在旋流室内形成液膜并破碎，结构简单，但对液体黏度极为敏感：黏度升高会使液膜增厚、破碎长度增加、液滴显著粗化，为维持雾化质量所需的喷射压力随黏度近似线性上升，能耗与设备负荷急剧增加；气助雾化依靠高速气流剪切液柱，可获得较细液滴，但需消耗大量雾化气，气液质量比（GLR）通常在 1 以上，运行成本高。气泡雾化（effervescent atomization）则是在喷嘴内部、液体排出之前，将少量气体以气泡形式直接注入液流，气液两相在混合室内形成泡状或弹状流，气泡在出口处因内外压差骤然膨胀爆裂，把液体撕碎成液滴。由于破碎能量主要来自气泡内部的膨胀功而非液体动能，气泡雾化的雾化质量对液体黏度不敏感，且所需 GLR 通常仅为 0.020.1，供气压力多在 0.30.6 MPa，是高黏度料液雾化的优选方案[1-4]。

气泡雾化的研究始于 Lefebvre 团队的系统工作。Chin 与 Lefebvre 建立了气泡雾化的流型分区图，指出混合室内存在泡状流、弹状流与环状流，流型直接决定出口液膜形态与最终粒径分布[2]；并给出了以排放孔面积 A*、气液比 GLR 为设计变量的设计程序，其中排放孔面积为

A* = m_l / [C_d · (2ρ_l ΔP)^0.5]

气液面积比与气液比满足 A*/A_a = 6.3 GLR，而可稳定工作的最大气液比为 GLR_max = 4.6 ρ_l / ρ_g[1]。Roesler 与 Lefebvre 实验考察了液滴尺寸随 GLR 与几何参数的变化规律，发现当 GLR 超过某一临界值后粒径下降趋于平缓[3]；Sovani 等对气泡雾化的机理、流型、粒径预测与几何影响作了系统综述，确认其在高黏度液体与低压供气条件下的独特优势[4]。此后研究进一步扩展到能量转换效率[5]、均匀液滴粒径分布的实现[6]、液体射流内鼓泡[7]、横流条件下的喷雾特性[8]、与气助雾化复合的联合雾化[9]等方面，应用领域涵盖燃烧、干燥、喷涂与制药[10,11]。

尽管气泡雾化在工程上已得到应用，但仍然存在三个突出问题。其一，现有研究以液滴粒径统计（如 SMD、D32）为主要评价指标，对喷雾近场的液膜破碎、液丝形成与液滴速度分布的时空结构刻画不足，而正是这些近场结构决定了后续破碎与蒸发过程[12,13]；其二，在曝气结构方面，传统的多孔管或狭缝注气方式形成的气泡尺度分布宽、流型稳定性差，采用烧结金属泡沫作为曝气元件可显著细化气泡并稳定流型，但相关的定量研究尚不多见；其三，多喷嘴阵列排布时相邻喷嘴喷雾重叠区的流场相互作用会改变局部液滴浓度与速度分布[14]，对喷雾场的均匀性影响尚需评估。

与液相结构相对应，喷雾过程的气相参数（温度、H2O 及其他组分浓度）同样是决定干燥速率与产品质量的关键量。可调谐二极管激光吸收光谱（TDLAS）技术凭借非侵入、高灵敏、快速响应与物种特异性等优势，已成为燃烧与流动诊断的主流手段[27,28]。其基本原理是 Beer-Lambert 定律：激光穿过待测区域后，透射光强与入射光强之比由吸收率积分决定，选取两条低态能级不同的水汽吸收线，由两线积分吸收面积之比即可通过双线比值法求出路径平均温度，再由温度与积分吸收率反演组分浓度[29-31]。该技术的时间响应可达 kHz 甚至 MHz 量级，且只需光学窗口，适合在喷雾干燥等工业现场部署。

在单点或单路径测量基础上，把多路激光按不同角度穿过待测区域，获得大量路径积分投影数据，再通过层析（CT）反演算法即可重建二维乃至三维的温度与浓度场分布，即激光吸收光谱层析成像[39]。近年来该技术已从早期的代数迭代（ART）与滤波反投影（FBP）发展到结合正则化的优化类算法[43,44]、视角配准的三维层析[47]以及基于神经网络的快速重建[49,50]，时间分辨率从 50 kHz 提升到可捕捉动态火焰的三维演化[41,50]。

然而，现有研究中液相结构诊断与气相场诊断基本是分离的：前者依赖高速成像、PIV、X 射线 CT 等[17-26]，后者依赖 TDLAS 层析[39-50]，两套系统各自独立采集，缺乏统一的时空基准与同步触发机制，因而难以建立"雾化结构—气相温度/浓度场"之间的定量关联，也无法在同一时刻判断液滴群分布与气相场是否匹配。这正是本课题提出的出发点：以气泡雾化喷嘴为对象，同步获取喷雾液相结构（液膜破碎、液滴粒径与速度）与气相温度、H2O 浓度场，形成联合诊断方法。

2、课题研究目的、理论意义和实际应用价值

（1）课题研究目的

1）针对高黏度料液难以高效雾化的问题，设计并优化气泡雾化喷嘴结构，明确混合室内气液两相流型、曝气元件特性与排放孔几何对雾化质量的影响规律，获得适用于食品料液的喷嘴设计参数。

2）建立喷雾液相结构光学诊断方法，获取近场液膜破碎形态、液滴粒径与速度分布及其统计特征。

3）搭建多路 TDLAS 层析测量系统，实现喷雾场气相温度与 H2O 浓度的二维分布重建，并评估投影角度数、网格分辨率与正则化参数对重建质量的影响。

4）建立液相结构与气相场的同步联合诊断方案与数据融合方法，在同一时空基准下揭示雾化结构与气相场的耦合关系。

（2）理论意义

揭示气泡雾化过程中"气液两相流型—出口液膜破碎—液滴粒径分布"的关联机制，丰富高黏度液体雾化的理论基础；建立金属泡沫曝气与分级注气条件下气泡尺度分布与流型稳定性的定量描述；阐明层析反演中投影角度数、网格尺度与正则化参数对重建精度与空间分辨率的影响规律，为吸收光谱层析在喷雾场中的应用提供参数选择依据。

（3）实际应用价值

为食品料液喷雾干燥与造粒装备的喷嘴选型与结构优化提供可直接采用的设计方法与数据；所建立的联合诊断方法可推广至喷雾干燥塔、喷雾燃烧室等工业装置的过程监测，实现雾化质量与气相参数的同步在线评估；TDLAS 层析系统的小型化与快速重建能力具备工业现场部署潜力，有助于降低干燥过程能耗、提升产品质量稳定性。

二、文献综述

1、国内外研究现状、发展动态

（1）气泡雾化喷嘴的研究现状

气泡雾化属于双流体雾化的一个分支，其区别于内部混合与外部混合气助雾化的本质，在于气体以气泡形式预先分散于液体内部，而非在出口处才与液体接触[4]。Lefebvre 与 McDonell 的专著系统总结了雾化的基本机理与各类喷嘴的设计准则[12]，为气泡雾化的研究奠定了理论基础。

在流型与机理方面，Chin 与 Lefebvre 通过透明喷嘴可视化实验，明确了混合室内泡状流、弹状流与环状流的转变边界及其对出口雾化形态的控制作用，指出泡状流条件下液滴最细且分布最稳定[2]；并提出了完整的设计程序，把排放孔面积、气孔面积与气液比关联起来[1]。Roesler 与 Lefebvre 进一步考察了液滴尺寸分布，发现增大 GLR 可减小 SMD 但存在收益递减现象，且排放孔长径比 L/D 接近 1 时雾化效果较好[3]。Ramamurthi 与 Rathakrishnan 研究了在液体射流内部直接鼓泡的方式，指出气泡在射流内的聚并与破裂行为决定了破碎长度[7]。Jedelsky 与 Jicha 从能量转换角度分析了气泡雾化的效率，量化了气体膨胀功向液体表面能与动能的分配关系[5]，并报道了在特定结构下可获得高度均匀的液滴粒径分布[6]。

在结构与工况适应性方面，Ghaffar 等综述了几何参数（气孔位置与数量、混合室长度、排放孔直径）对喷雾特性的影响[11]；Ozgoren 等考察了横流条件下气泡雾化喷雾的偏转与粒径变化[8]；Kourmatzis 等把气泡雾化与气助雾化复合，用于改善液体射流的雾化与混合[9]；Santangelo 对商用气泡雾化喷嘴的高压水喷雾作了表征[16]。应用层面，Zhao 等综述了气泡雾化在燃烧、干燥、喷涂、制药等领域的工程应用现状[10]。国内方面，赵芳等针对旋流式气泡雾化喷嘴开展了喷雾特性实验，分析了旋流强度与气液比对雾锥角与粒径的影响[15]。针对高黏度与过热液体，Li 等利用透明狭缝喷嘴研究了过热液体射流破碎与气泡形成的相关性[13]。在多喷嘴排布方面，Yan 等实验研究了多喷嘴阵列中相邻喷雾重叠区的流场相互作用[14]，为阵列化布置提供了参考。

（2）喷雾液相结构测量技术的研究现状

喷雾液相结构的诊断手段可大致分为点式、平面式与体式三类。早期 Yule 等采用激光层析方法对液体燃料喷雾的密度分布进行了重建，是最早将层析思想引入喷雾测量的工作之一[17]。平面测量方面，Hardalupas 等将离焦成像技术（ILIDS）与 PIV 结合，实现了液滴速度、粒径与气相速度的同时平面测量[22]；Mishra 等把结构光照明平面成像（SLIPI）与 LIF/Mie 比值法结合，有效抑制了稠密喷雾中的多重散射与二次光，显著提高了 SMD 二维分布的可靠性[21]；Angarita-Jaimes 等利用紫外荧光示踪粒子实现了 GDI 喷雾的气相与液相三分量速度同步测量[23]；Omrane 等发展了基于热像荧光磷光体的二维液滴与喷雾温度成像方法[18]。

体式与高时空分辨测量是近年来的重要方向。Klinner 与 Willert 提出了用于喷雾诊断的层析阴影法，可从多角度阴影图像重建喷雾的三维密度分布[24]；Singh 等利用图像切片法测量雾化碎片的体积分布[25]。最具突破性的是基于同步辐射的 X 射线成像：Halls 等实现了 kHz 帧率下液体喷雾四维时空演化的 X 射线 CT 重建[19]，并进一步发展了多相流的四维 X 射线成像方法[20]，首次在不引入光学散射干扰的条件下直接获得喷雾近场的液相质量分布。Zhang 等对液体燃料雾化与蒸发的激光诊断技术作了系统综述[26]。

上述方法各有局限：接触式取样会干扰流场；基于mie散射与荧光的平面方法在稠密喷雾中受多重散射影响严重，需借助 SLIPI 等抑制手段；X 射线 CT 虽精度高但依赖同步辐射装置，难以在工业现场应用。更重要的是，这些液相诊断手段与气相场测量通常是分离的，缺乏同步机制。

（3）TDLAS 吸收光谱测温与层析成像的研究现状

TDLAS 技术的发展可追溯至可调谐二极管激光器在燃烧气体测量中的应用。Arroyo 与 Hanson 利用 InGaAsP 分布反馈激光器实现了水汽浓度、温度与线型参数的同时测量[29]；Rieker 等发展了可在高温下快速测量气体温度与水汽浓度的二极管激光传感器[31]；Cai 等利用 1.4 μm 附近的单支可调谐二极管激光器实现了温度与水汽浓度的同时测量[30]。在谱线参数方面，Schroeder 等对比了 HITRAN2012 与 HITEMP2010 数据库在高温下水汽吸收的预测差异[32]，Rothman 等发布的高温分子光谱数据库 HITEMP 为高温诊断提供了基础数据[33]，Kochanov 等开发的 HITRAN 应用程序接口（HAPI）极大便利了谱线仿真[34]。Goldenstein 等对红外激光吸收传感在燃烧气体中的应用作了权威综述[27]，Hanson 与 Davidson 综述了激光吸收方法在燃烧化学研究中的最新进展[28]。

国内研究方面，李飞等利用 TDLAS 测量了甲烷/空气预混平面火焰的温度与 H2O 浓度[35]；夏晖晖等基于 TDLAS 多线吸收实现了直连台架燃烧场温度与组分浓度的二维分布测量[36]；苟等测量了 1.39 μm 附近 H2O 的谱线参数并用于燃烧动力学[38]；李等系统研究了 TDLAS 温度测量的不确定度评定方法[37]。

在层析成像方面，Cai 与 Kaminski 系统综述了吸收光谱层析在气体动力学与燃烧研究中的原理、算法与应用[39]。Ma 等提出了基于高光谱吸收的层析成像方法，实现了温度与化学组分的二维重建[40]，并进一步发展为 50 kHz 帧率的二维温度与 H2O 浓度成像[41]。Wang 等实现了气体浓度与温度分布的二维层析重建[42]。在反演算法上，Guha 与 Schoegl 采用 Tikhonov 正则化改善层析重建的病态性[43]；Xia 等提出两步层析重建策略分别反演温度与组分浓度[44]；Liu 等研究了 TDLAS 层析中空间分辨率的定制方法[45]。在三维与快速重建方面，Wei 等实现了燃烧组分与温度的三维层析吸收成像[46]；Yu 等发展了面向燃烧诊断的实时体积层析方法[48]；Liu 等把视角配准引入三维层析并应用于高湍流火焰[47]；Si 等提出了质量分层的温度成像网络，可同时输出实时监测与高精度离线重建结果[49]；Gao 等实现了动态火焰的三维温度成像[50]。

总体来看，TDLAS 层析已趋于成熟，但仍存在两方面不足：一是投影角度数、网格分辨率与正则化参数的选取多依赖经验，针对喷雾这种弱吸收、低浓度、强散射环境缺少系统的参数评估；二是研究对象几乎全部集中在燃烧火焰，针对常温喷雾场（无高温辐射背景、水汽浓度受蒸发影响）的应用报道很少，相关的谱线选择与反演策略需要重新论证。

（4）现有研究存在的不足

综合上述三个方面的调研，现有研究存在以下不足，构成本课题的切入点：

1）气泡雾化的研究以液滴粒径统计为主要评价指标，混合室内气液两相流型、曝气元件特性与排放孔几何对近场破碎结构的定量关联研究不足，针对高黏度料液的系统数据尤为缺乏。

2）喷雾液相结构诊断（高速成像/PIV/X 射线 CT）与气相场诊断（TDLAS 层析）基本处于分离状态，缺少同步触发与统一时空基准，难以建立"雾化结构—气相温度/浓度场"的定量对应关系。

3）吸收光谱层析的反演参数（角度数、网格、正则化）选择多依赖经验，缺少针对喷雾工况的系统性评估；且层析对象多为燃烧火焰，常温喷雾场的应用尚需验证。

三、研究内容、技术路线、创新点

1．主要研究内容及拟解决的关键技术

（1）主要研究内容

1）气泡雾化喷嘴结构设计与优化。

以 Chin–Lefebvre 设计程序为起点，结合高黏度料液的物性参数（密度 ρ_l、动力黏度 μ、表面张力 σ）确定排放孔面积 A* 与气孔面积 A_a，按 A*/A_a = 6.3 GLR 与 GLR_max = 4.6 ρ_l/ρ_g 校核工作区间。混合室取直径 φ15 mm、轴向长度 28 mm，排放孔直径 φ1.02.0 mm 可调、长径比 L/D ≈ 1。重点研究两类结构改进：一是采用 316L 烧结金属泡沫（孔径 1050 μm）作为曝气元件，细化气泡尺度并稳定泡状流；二是设计 Y 型三级结构，即一级双路 45° 对冲注气 + 二级金属泡沫独立腔体 + 三级可更换排放螺帽（M30×1.5），解决单级结构中气体易短路、液体易回流进入气路的问题。通过改变 GLR、供气压力与料液黏度，测量雾锥角、破碎长度与液滴粒径分布，建立结构参数与雾化质量的定量关系。

2）喷雾液相结构光学诊断。

采用高速相机与片光照明获取喷雾近场图像，结合背景去除、二值化与频域滤波提取液相边界；利用 PIV 处理获得液相速度场与时间平均流线，并通过荧光示踪与 Mie 散射的强度与尺寸差异区分液滴与示踪粒子，统计液滴与颗粒的速度分布特征。考察不通气与通气两种典型工况：不通气时液体自排放孔射出形成连续液柱，通气后（气压约 0.4 MPa）液柱消失并形成张角约 15°~20° 的雾化锥。

3）气相温度与浓度场 TDLAS 层析测量。

选取 1948 nm 与 1962 nm 两支分布反馈激光器对应的水汽吸收线（波数分别为 5132.96 cm⁻¹ 与 5096.60 cm⁻¹，低态能级差 ΔE″ ≈ 248 cm⁻¹），由双线积分吸收面积比求取路径平均温度。设计 32 路平行光路、相邻间距 35 mm（总宽 1120 mm），通过旋转 CT 转台获取多角度投影，重建区域划分为 32×32 网格，采用 Tomopy 工具包中的 ART、SIRT 与 Tikhonov 正则化等算法进行反演，并系统比较投影角度数（50、72、100、150）对重建质量的影响。

4）液相结构与气相场的联合诊断与数据融合。

设计统一的同步触发时序，使高速相机、TDLAS 数据采集卡与 CT 转台在同一时钟基准下工作；建立液相图像坐标与层析网格坐标的映射关系，实现同一时刻液相结构（液滴浓度、速度）与气相场（温度、H2O 浓度）的空间配准与联合可视化；在此基础上分析雾化状态变化对气相场的影响，并对联合诊断的不确定度进行评定。

（2）拟解决的关键技术

1）高黏度料液的稳定雾化技术。通过金属泡沫曝气细化气泡、Y 型分级注气阻断气体短路与液体回流，实现低 GLR 条件下高黏度料液的稳定细雾化。

2）多路光束的同步采集与投影角度优化技术。解决 32 路光路的光强归一化、探测器一致性标定与转台角度定位精度问题，并确定满足重建精度所需的最少角度数。

3）液相与气相数据的时空配准技术。解决两套诊断系统采样率与空间分辨率差异带来的配准误差，实现融合分析。

2．拟采取的研究方法、技术路线、实施方案及可行性分析

（1）研究方法

1）理论分析与数值模拟：依据 Chin–Lefebvre 设计程序进行喷嘴参数计算，利用 CFD 模拟混合室内气液两相流型与出口液膜形态，对结构方案进行预评估。

2）光谱仿真：基于 HITRAN/HITEMP 数据库仿真水汽在候选波段内的吸收光谱，选取吸收强度适中、无邻近谱线干扰且对温度敏感的双线对。

3）实验研究：搭建喷雾实验台与 32 路 TDLAS 层析系统，分别在液相侧与气相侧开展测量，并进行联合诊断实验。

4）数据处理与不确定度分析：采用层析反演算法重建温度与浓度场，结合谱线参数不确定度、探测器噪声与角度定位误差评定测量不确定度。

（2）技术路线与实施方案

技术路线按"结构设计—光谱选线—液相诊断—气相层析—联合诊断"五个环节推进：首先针对高黏度料液雾化需求完成喷嘴结构设计与仿真优化；其次通过光谱仿真确定测量谱线并完成 TDLAS 系统标定；随后分别开展液相结构光学诊断与气相场层析测量实验；最后建立同步联合诊断方案并完成数据融合与不确定度分析。

实施方案：

1）喷嘴设计与加工。完成三级 Y 型气泡雾化喷嘴的结构设计，加工混合室、金属泡沫腔体与可更换排放螺帽，搭建供气（气瓶—减压阀—流量计）与供液管路。

2）光谱选线与系统标定。利用 HITRAN/HITEMP 数据库仿真确定 1948 nm 与 1962 nm对应的吸收线对，完成激光器温控与电流扫描标定、探测器响应一致性标定及 32 路光强归一化。

3）液相结构实验。在不通气与通气（0.2~0.6 MPa）工况下拍摄喷雾形态，获得雾锥角、破碎长度与液滴速度统计。

4）气相层析实验。采集多角度投影数据，比较不同角度数与反演算法下的重建结果，确定最优参数组合并重建温度与 H2O 浓度二维分布。

5）联合诊断与论文撰写。实现同步触发与数据融合，完成数据分析与学位论文撰写。

（3）可行性分析

1）理论与技术可行。气泡雾化的设计方法与流型理论已较为成熟[1-4]，TDLAS 双线测温与吸收光谱层析在燃烧诊断中已有大量成功案例[27,39,40]，将其迁移至常温喷雾场在原理上不存在障碍；前期已完成喷嘴原型加工并开展了通气/不通气对比实验，验证了雾化方案的可行性。

2）实验条件可行。课题组已具备激光器、光电探测器、数据采集卡、高速相机、流量计、光学平台等硬件条件，并配有数值模拟与数据处理软件；32 路光路与 CT 转台已具备加工与搭建条件。

3．论文的创新点

1）提出金属泡沫曝气与 Y 型三级分级注气相结合的气泡雾化喷嘴结构，通过独立腔体与可更换排放螺帽设计，在抑制气体短路与液体回流的同时实现低气液比下高黏度料液的稳定细雾化。

2）建立喷雾液相结构光学诊断与气相 TDLAS 层析的同步联合诊断方法，在同一时空基准下同时获取液滴粒径/速度与气相温度/H2O 浓度分布，突破了现有研究中液气两相分离测量的局限。

3）系统评估投影角度数、网格分辨率与正则化参数对喷雾场层析重建质量的影响，给出适用于常温弱吸收喷雾场的参数选择依据。
