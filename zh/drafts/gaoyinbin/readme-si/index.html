303-1 论文 Supporting Information：脚本与数据说明

本包提供论文《Integrating the JANAF Thermochemical Tables into the Undergraduate Thermal Engineering Curriculum》的可复现脚本与数据：12 个 Python 脚本 + 1 张 JANAF 原始物种表目录（janaf_data/，16 个文件）+ 沿程剖面数据（nozzle_profiles.npz）。

数值口径（现行稿，2026-09-20）：燃烧室 $T_c$ = 3756 K（5 物种 JANAF 手算）/ 3730 K（Cantera）；喉道 $p_t$ = 116.87 bar（冻结）/ 116.38 bar（平衡），由 $u_t=a_t$ 迭代定出（不是 $\gamma$ 常数阻塞式近似）；$T_t$ = 3398 K（冻结）/ 3507 K（平衡）。

一、环境要求

pip install numpy scipy matplotlib     # 数据图与核验脚本
pip install cantera                    # 仅 Example 8 的 4 张图需要（Cantera ≥ 3.0，用 gri30.yaml）
  • 零 Cantera 依赖：Example 1–7 的全部数据图（8 张）+ 全部数值核验脚本 + Ex8 的纯 JANAF 求解脚本。
  • 需 Cantera：ex8_exit_cstar.py、make_profiles_data.py、make_fig_hs.py、make_fig_sound_speed.py（论文 Figure 8_hs / 08_profiles / 08_sound_speed 及其数据）。
  • 所有画图脚本可用环境变量 FIGDIR 指定输出目录，默认写到脚本同级 fig/。

三、运行方式

cd 脚本与数据

# ① 数值核验（零 Cantera）
python3 verify_paper_numbers.py      # 全 PASS，退出码 0
python3 ex8_full.py                  # 纯 JANAF 口径：T_c=3756 K、p_t=116.9 bar、T_t=3417 K
python3 ex8_sp_path.py               # 冻结流 SP 沿程

# ② Example 1–7 数据图（零 Cantera，8 张）
python3 make_figs_jce.py             # Figure 1–5 → fig/Figure111.png, Figure222.png, 01/04/05.png
python3 redraw_ex7_fig6_fig7.py      # Figure 6–7 → fig/06.png, 07.png

# ③ Example 8 的 4 张图（需 Cantera）
python3 ex8_exit_cstar.py            # 段4 出口表 + 段6 c*/CF/Isp（文本输出）
python3 make_profiles_data.py        # → nozzle_profiles.npz
python3 make_fig_nozzle_profiles.py  # → fig/08_profiles.png（需先跑上一步）
python3 make_fig_hs.py               # → fig/08_hs.png
python3 make_fig_sound_speed.py      # → fig/08_sound_speed.png

四、数值锚点（用于判断脚本跑对没跑对）

量值来源

燃烧室组成（摩尔分数）H₂O 0.661 / H₂ 0.249 / H 0.035 / OH 0.051 / O₂ 0.004同上
$p_t$（喉道）116.87 bar（冻结，$u_t=a_t$ 迭代） / 116.38 bar（平衡）verify_throat_strict.py
$T_t$（喉道）3398 K（冻结） / 3507 K（平衡）ex8_exit_cstar.py
出口（$A_e/A_t$=20）$T_e$ = 1440 K（冻结）/ 1844 K（平衡）；$I_{sp,\text{vac}}$ = 411 / 424 sex8_exit_cstar.py

Ex6 火焰温度$T_f$ ≈ 2326 K（CH₄–空气，ξ=1 时 2327 K）同上
计量自检O/F = 6.0（质量比）⇔ 每 mol O₂ 配 2.6456 mol H₂（$M_{\mathrm{O_2}}/(n_{\mathrm{H_2}}M_{\mathrm{H_2}})=6.000$）所有 Ex8 脚本

五、JANAF 数据列索引（janaf_data/*.txt，制表符分隔）

0=T(K)  1=Cp  2=S  3=-[G-H(Tr)]/T  4=H-H(Tr)  5=ΔfH  6=ΔfG  7=logKf
  • 单位：$C_p$、$S$ 为 J/(mol·K)；H 类与 G 类为 kJ/mol；Tr = 298.15 K。
  • 绝对焓（元素 298.15 K 为零点）：$H_i(T)=\Delta_fH_i(298.15)+[H_i(T)-H_i(298.15)]$， 不能用温度相关的 $\Delta_fH(T)$ 再加显焓（会双重计算）。

六、文献与术语口径

  • HP / SP / UV 等约束对术语依 NASA RP-1311（Gordon & McBride, 1994）；
  • 双口径（frozen / equilibrium）与 NASA CEA 对照仅作验证用途，正文数值以 JANAF 表与上述脚本为准。
